# 1kg単位の体型変化 仕様案 v0.1

2026-11-02 データ検証セッションで作成。基幹セッション・キャラ設定セッションへの提案。
立ち絵は15段階（15枚）のまま。段階の間の細かい変化を「数値」「文章」「イベント」で1kg単位に見せる。

## 方針と前提
- 立ち絵の段階8〜14は、1段階あたり横幅2〜3%の差しかない。ChatGPTの出力のぶれ（±3〜5%）と同じくらいなので、画像の枚数を増やしても描き分けられない。細かい変化は画像以外で出す
- 現在の増え方：kcalPerKg 7000 ÷ weightGainBoost 2.5 ＝ **約2,800kcalの余剰で1kg増**。ドーナツ6個入り（1,400kcal）で約0.5kg。1kgの変化は数日に1回くらい起きる。毎回イベントにすると多すぎるので、表示と出し方に優先順位をつける（下記「出し方のルール」）
- 参考：現実の体脂肪1kgは約7,200kcal。7,000は妥当

## 1. 数値（毎回の訪問で表示）
すでに決まっている式で計算できる。エンジンへの実装が必要（システム仕様では「スリーサイズの計算・表示は未実装」）。
- 体重（0.1kg単位）、BMI（小数1桁）、前回会ったときからの増減（例：「+1.2kg」）
- スリーサイズ：段階1の値＋体型タイプの係数×増えた体重（体型タイプ仕様の表。BMI39以上はWに+0.2cm/kg）
- アンダーバスト：+0.45cm/kg。カップ＝バスト−アンダー（2.5cmごとに1カップ。A＝10cm）
- **服のサイズ**（下の表で判定）。上はバスト、下はウエストとヒップの大きいほうで決める
- 表示する場所：部屋の訪問画面の「プロフィール」欄。体重を見せるかは親密度で変える案もある（よそよそしいうちは「？？kg」、好意以上で本人が教えてくれる）

### 服のサイズ表（JISの女性用サイズ）
| サイズ | バスト | ウエスト | ヒップ |
|---|---|---|---|
| S | 72〜80 | 58〜64 | 82〜90 |
| M | 79〜87 | 64〜70 | 87〜95 |
| L | 86〜94 | 69〜77 | 92〜100 |
| LL | 93〜101 | 77〜85 | 97〜105 |
| 3L | 100〜108 | 85〜93 | 102〜110 |
| 4L | 107〜115 | 93〜101 | 107〜115 |
| 5L | 114〜122 | 101〜109 | 112〜120 |
| 6L〜9L | 以降、バスト・ウエストは+8cm、ヒップは+5cmずつ（JISの表にはないので外挿。大きいサイズ専門店の扱い） |

- 1kgでウエストが約1〜1.35cm増えるので、**服のサイズは3〜5kgごとに1つ上がる**（試算：沙耶は53→120kgで上下合わせて18回、ことりは14回）
- 胸の大きいキャラ（小百合・玲奈）は、上の服をバストだけで決めると小さめに出る。「胸がきつい」演出に使える

## 2. 文章（体重が1kg変わるごとに少しずつ変わる）
### 2-1. 服のきつさ（いちばん1kg単位の変化が伝わる）
今着ている服のサイズの範囲の中で、どこまで来ているかで文章を変える。服のサイズの上限まで残り何cmかで判定する。
| 残り | 状態 | 文章の例（りんご型・ウエスト） |
|---|---|---|
| 5cm以上 | ゆとり | 服はまだ余裕がありそうだ |
| 3〜5cm | ぴったり | ウエストがちょうどいい、と本人は言う |
| 1〜3cm | きつい | ボタンのまわりに、小さなしわが寄っている |
| 0〜1cm | 限界 | ボタンが今にも弾けそうだ。座るたびに息を止めている |
| 超えた | 買い替え | → 服のサイズアップのイベント（3. イベント） |
- 判定する部位は脂肪型で変える：りんご型＝ウエスト、洋梨型＝ヒップ、隠れ肥満型＝全部の平均（隠れ肥満は段階4まで判定を遅らせる）
- 立ち絵の服装グループ（段階1〜4／5〜8／9〜12／13〜15）とは別に動く。ゲーム内の「今の服」は文章だけで、立ち絵の服は段階で切り替わる（ずれても問題ない）

### 2-2. 体の様子（体型メモの細分化）
今の段階の体型メモ（stages の desc）に、段階の中での位置に応じて一言を足す。
- 段階の範囲の前半：「〇〇になったばかりだ」（例：「お腹がはっきり丸く出はじめたばかりだ」）
- 後半：「次の段階の特徴が少し見えはじめている」（例：段階6の後半で「顔の輪郭も丸くなってきた」＝段階7の特徴を先取り）
- 1段階に2〜3行あれば足りる。脂肪型ごとに言い回しを変える

### 2-3. 前回からの変化（主人公の気づき）
訪問したとき、前回会ったときからの増減で一言出す。
| 増減 | 文章の例 |
|---|---|
| +0.5kg未満 | （出さない） |
| +0.5〜1.5kg | 「気のせいか、頬が少し丸くなった気がする」 |
| +1.5〜3kg | 「ほんの数日で、また一回り丸くなった」 |
| +3kg以上 | 「明らかに太った。本人も気づいているはずだ」 |
| 減った | 「少しすっきりした…？」（食事を抜いた、断られた日が続いた） |

## 3. イベント（節目の体重で1回だけ）
現実のデータで節目を決める。各イベントは「起きた後の最初の訪問」で出し、1回の訪問で出すのは1つだけ（残りは次回に回す）。
| 種類 | 発生条件 | 内容の例 |
|---|---|---|
| 服のサイズアップ | 服のきつさが「買い替え」になった | 「Lが入らなくて、LLを買ったの」。サイズ名を本人が言う。恥じらい期は言わずにごまかす |
| キリのいい体重 | 60・70・80・90・100・110kgを初めて超えた | 「体重計、見間違いかと思った」。100kgは特別なイベント（大台） |
| 初期体重から | +10kg、+20kg、初期体重の1.5倍、2倍 | 2倍は大きな節目（ことり40→80kg、ひなた49→98kg） |
| 肥満度の区分 | BMI25・30・35・40を超えた（日本肥満学会の肥満1〜4度の境目） | 大学・会社の健康診断の結果。「肥満2度って書いてあった…」 |
| 腹囲 | ウエスト90cm以上（日本のメタボ健診の女性の基準） | 健康診断で「腹囲が基準を超えてます」と言われる |
| 体型の逆転 | りんご型：ウエストがバストを超えた／洋梨型：ヒップがバストを20cm以上上回った | りんご型「お腹のほうが出てる…」 |
| 体重計 | 100kgを超えた | 安い体重計の上限を超えてエラーになる（家庭用は上限100〜150kgのものが多い） |
| 段階が上がった | 今までどおり（stageUp） | 立ち絵が変わる。これは最優先 |
- 試算では、服のサイズアップだけで1キャラ14〜18回、ほかの節目と合わせて25〜30回ほど起きる。0〜120kgの間で、約2〜3kgに1回のイベントになる
- 優先順：段階アップ ＞ 100kg・2倍などの大きな節目 ＞ 服のサイズアップ ＞ そのほか

## 5. セリフの量の目安（キャラ設定セッション向け）
- 共通（脂肪型3種×イベント7種×low/high）：約40本。これがあれば全ヒロインで動く
- ヒロイン固有は、大きな節目（100kg・2倍・最初の服のサイズアップ）だけでも足りる：1人6〜10本
- 服のきつさ・体の様子・前回からの変化は地の文（主人公の視点）なので、ヒロインごとに書かなくてよい

## 6. 気になる点（検証メモ）
- 維持カロリー（体重×28kcal）は、体重が重くなるほど現実より多めになる（120kgで3,360kcal。現実の座りがちな女性は2,400〜2,600kcal程度）。高い段階ほど太りにくくなり、イベントの間隔も空く。ゲームの手応えとして意図どおりなら問題ない
- 体重を毎回見せるかどうかは、心理の流れ（強がり期は体重計に乗らない、など）と合わせて決めるとよい。例：強がり期は「本人は教えてくれない」、恥じらい期は「小声で教えてくれる」、受け入れ期は「自分から言う」
