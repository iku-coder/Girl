## 新しい物語
ひだまり荘は、住人たちの体重の増加で床と柱が限界になった。主人公はレジデンスと土地を担保に奥の土地を買い、15階建ての「ひだまりタワー（仮）」を建てた。ひだまり荘の7人（hinata・saya・reina・sayuri・akane・kotori・yukino）は、主人公の好意で1階の新しい部屋に**家賃5万円（これまで＋1万円）**で引っ越した。15階は主人公のプライベートルーム（いくつもの風呂、ベッドルーム、プライベートプール、大きなデッキ）。攻略した住人をそこに誘える。

## 1ファイル＝1人。中身は addExtra だけ
```js
window.addExtra('<id>', { lines: {
  towerMove: ['…', '…'],   // ひだまり荘の7人だけ。引っ越しの日、新しい1階の部屋を見た一言（古いアパートへの思い、床がきしまない、エレベーター、家賃のお礼、太ったことへの照れなど）
  invite15: ['…', '…'],    // 15階のプライベートルームに初めて呼ばれて、エレベーターを降りた一言（夜景、広さ、ベッドの大きさなど。甘い雰囲気でよいが性的な描写はしない）
  pool: ['…', '…'],        // プライベートプールに誘われて（水着がきつい、浮き輪、プールサイドのランチなど。体型の段階に関係なく通じる一言に）
  bath: ['…', '…']         // 15階のいちばん広い風呂に案内されて（足をのばせる、いくつもの風呂、湯上がりのアイスなど。お風呂の中の描写・裸の描写はしない）
} });
```
- どれも「攻略したあと」に出るので、攻略後の口調・呼び方（主人公の名前は「〇〇」）で。towerMove は攻略前にも出るので、呼びかけは省く
- 口調は /home/claude/hidamari/heroines.js（ひなた・沙耶は /home/claude/hidamari/data.js の heroines）と、そのキャラのシーン（/home/claude/hidamari/scenes/<id>.js、scenes/room/<id>.js、春香・杏は scenes/hero/haruka.js・anzu.js）に合わせる
