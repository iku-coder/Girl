## ゲーム本体（基幹セッション）

ブラウザゲーム「ひだまり荘」（試作版 v0.9）。ビルド不要で、`index.html` をブラウザで開けば動く（立ち絵は `img/` を読む）。

| ファイル | 内容 |
|---|---|
| `index.html` | エンジンと画面（時間の進行、親密度、会話シーン、体重計算、服のサイズ・節目イベント、マンション編） |
| `data.js` | 数値バランス、体型段階、節目イベントと全キャラ共通の予備セリフ、ひなた・沙耶のデータ |
| `heroines.js` | 追加ヒロイン16人のデータと基本のセリフ（立ち絵が15段階そろったキャラ） |
| `life.js` | 体型が変わったあとの生活の変化（`docs/ヒロイン設定.md` から自動生成） |
| `scenes/<id>.js` | キャラごとの選択肢つき会話シーン（16人×16〜17場面）と、太ったときの一言・節目のセリフ |
| `tools/check_scenes.js` | 会話ファイルの形式チェック（`node tools/check_scenes.js scenes/*.js`） |
| `scenes.js` | 選択肢つきの会話シーン（朝の挨拶・荷物・家賃回収・部屋で話す）。書き方はファイル冒頭のコメント |

- ヒロインの追加・調整は `data.js`、会話の追加は `scenes.js` だけを書き換えれば反映される
- 立ち絵は各ヒロインの `images` に `img/<id>_<段階>.png` を登録する（現在17人分。ひなたは画像がまだリポジトリにないので仮シルエット、雪乃は立ち絵がそろってから登録）
- 仕様の全体は `docs/システム仕様.md`

## 設定資料（`docs/`）

キャラ設定セッションが管理する設定資料。claude.ai のプロジェクト「ゲーム制作」の同名ファイルと同じ内容。

| ファイル | 内容 |
|---|---|
| `docs/ヒロイン設定.md` | 全ヒロインの設定（プロフィール・外見・段階ごとの服装と髪型・太った後の性格と生活・体型段階ごとの目安・段階1のTsubaki用プロンプト・data.js 用の値） |
| `docs/キャラ設定_新キャラ引き継ぎ.md` | キャラ設定セッション → キャラデザセッションへの新キャラの引き継ぎと、基幹セッションへの依頼 |
| `docs/体型タイプ仕様.md` | 骨格×脂肪型の体型タイプの仕様と、各ヒロインの割り当て |
| `docs/節目イベント_セリフ.md` | 体型の節目イベントのセリフ |
| `docs/システム仕様.md` | ゲームのシステム仕様（基幹セッションが管理）。ルール、親密度、会話シーン、体型変化、節目イベント、マンション編、data.js の書き方 |
