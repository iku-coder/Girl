- GitHub: iku-coder/Girl（ルートに index.html・data.js・scenes.js、仕様は docs/システム仕様.md、立ち絵は img/）。基幹セッションが更新したらここにも反映する
- 構成: `index.html`（エンジン・画面）＋ `data.js`（数値・ひなたと沙耶・共通セリフ・うわさ）＋ `heroines.js`（追加ヒロイン16人）＋ `life.js`（体型が変わったあとの生活の変化。ヒロイン設定から自動生成）＋ `scenes.js`（ひなた・沙耶の会話シーン）＋ `scenes/<id>.js`（キャラごとの会話シーンと太ったときの一言）
- ヒロインの数値は data.js、会話は scenes.js を書き換えれば反映される。最新版はプロジェクトの `claude/data.js`・`claude/scenes.js`

## 基本ルール
- 主人公: 20歳・大学2年。祖父から相続した木造2階建てアパート（8室）の管理人。101号室が自室
- 1日は「朝・昼・夕・夜」の4コマ。行動1回で1コマ進む。夜の行動後に1日が終わり、夜の集計で体重が変わる
- ゲームは **2026年4月1日（水）** から始まる（data.js の startDate）。曜日・月末はカレンダーどおり
- 家賃は月4万円／人。**月末の家賃回収イベント**で受け取る
- 住人は全員成人

### 序盤のイベント（全段階で起きるが、0〜34では主な交流手段）
- **朝の挨拶**：朝に「敷地の掃除」をすると、ヒロインごとに35%で挨拶イベント（親密度 +3）。セリフ greetMorning
- **宅配物の預かりと引き渡し**：昼になったとき、留守のヒロインごとに12%で荷物を預かる。在室中にドアをタップすると渡せる（行動を消費しない）。翌日までなら +4（packageReceive）、2日目以降は +1（packageLate）。3日目の夜に本人が取りに来る（親密度 −2）
- **月末の家賃回収**：月末の日はドアに「家賃」が付き、在室中にタップすると回収（行動を消費しない）。回収しないまま夜になると、封筒で受け取る（交流なし）
  - 0〜34：嫌な顔（rent[0]）、+1
  - 35〜69：雑談まじり（rent シーン）、+3。50%で追加イベント（rentExtra シーン）
  - 70〜：好意的（rent[2]・[3]）、+2

## 会話シーン（scenes.js）
朝の挨拶・荷物・家賃回収・部屋の「話す」は、すべて**選択肢つきの会話シーン**で進む。主人公の返答で相手の反応・親密度・その後の会話が変わる。

- **種類（type）**：morning（朝の挨拶）／package（荷物）／rent（家賃回収）／rentExtra（家賃回収の追加イベント。顔なじみのとき50%）／talk（部屋で話す）
- **選ばれ方**：条件（if）に合うシーンのうち、まだ見ていない（見た回数が少ない）ものからランダム。同じ会話が続きにくい
- **条件**：親密度の段階（tiers）、親密度の範囲、フラグ、荷物が遅れたか（late）、休日か、時間帯、攻略済みか、体型段階、所持金、確率
- **ノード**：セリフ → 効果 → 自動分岐（branch）／選択肢（choices）／次へ（next）。何段でも続けられる
- **効果**：親密度（aff）、警戒（wary）、建物の状態、お金、食習慣（habit）、フラグの付け外し
- **フラグ**：選んだ返答を覚えておき、後の会話や選択肢の出現に使う（例：「料理を作る」と約束 → 後日「覚えてる？」の会話。「なんだっけ？」と答えると親密度が下がる）
- **一度きり（once）**：身の上話など、1回だけのシーン
- 選択肢の表示中は他の操作ができない。親密度の段階が上がった通知や攻略イベントは、シーンが終わってから出る
- シーンが1つもないときは、data.js の lines（greetMorning など）を予備として使う
- 基本の親密度上昇（朝の挨拶 +3、荷物 +4/+1、家賃 +1/+3/+2、話す +4）に、選択肢の増減が加わる

書き方の詳細は scenes.js の冒頭のコメントを参照。

## 体型が変わる仕組み
- 体重変化（夜）＝（自炊分 ＋ 差し入れ・食事のカロリー − 維持カロリー）÷ 7000 × 2.5
  - 維持カロリー（体重×28）は重くなるほど現実より多めで、高い段階ほど太りにくい。後半の手応えとして**このままにする**（2026-11-02 ユーザー決定）
  - 維持カロリー＝体重×28、自炊分＝維持カロリー×(0.97 ＋ 0.5×食習慣)
- **食習慣**: 食べさせるほど上がり（差し入れ+1%、外食+3%、手料理+4%）、毎日少しずつ下がる
- **満腹と胃袋**: 満腹ゲージが上限を超える差し入れは断られる。上限の8割以上まで食べると上限が+2広がる
- **警戒**（好意70未満のみ）: 差し入れの回数オーバー、満腹で断られる、体型が変わる、で上昇。60以上で差し入れ拒否、80以上で訪問拒否。毎晩 −10
- **ヒロイン別の補正**（任意）: `mods: { habitDecay: 0.5, stretch: 1.5 }`（食習慣の減り方・胃袋の広がり方の倍率。雪乃の提案に対応）

## 1kg単位の変化（v0.6。1kg単位の変化_仕様案 v0.1 を実装）
立ち絵は15枚のまま。段階の間の細かい変化を、数値・文章・節目イベントで見せる。

### 数値（部屋の画面）
- 体重・BMI・スリーサイズ（カップ付き）。スリーサイズ＝段階1の値（ヒロインの sizes）＋体型タイプの係数×増えた体重。BMI39を超えた分はウエスト +0.2cm/kg。アンダーは +0.45cm/kg、カップは（バスト−アンダー−10）÷2.5 を四捨五入（A＝10cm）
- **体重を教えてくれるか**（weightReveal）：好意（70）未満は「？？kg」／段階5〜8は強がって教えない／段階9〜12は小声で教える／段階1〜4・13〜15と攻略後は表示。開発メニューの「体重を常に表示」で切り替え可
- 服のサイズ（上／下）は見た目なので常に表示

### 文章
- **服のきつさ**：今の服の上限まで残り何cmか（りんご型＝ウエスト、洋梨型＝ヒップ、隠れ肥満型＝平均。隠れ肥満は段階4まで「余裕」のまま）。ゆとり／ちょうどいい／しわ／弾けそう
- **体の様子**：体型メモに「〇〇になったばかりだ」（段階の前半）／「少しずつ『次の段階』の気配が見えはじめている」（後半）を足す
- **前回からの変化**：訪問時、前回会ったときからの増減で主人公の一言（+0.5kg未満は出さない）

### 服のサイズ（clothingSizes）
JIS女性用 S〜5L、6L以降は外挿（12Lまで）。上はバスト、下はウエストとヒップの大きいほうで決める。今の服は**上がるだけ**で、上限を超えた夜に買い替え（服のサイズアップのイベント）。

### 節目イベント
夜の集計で節目を越えたら積んでおき、**次の訪問で1つだけ**出す（eventsPerVisit）。優先順：段階アップ ＞ 100kg・最初の2倍 ＞ 服のサイズアップ ＞ そのほか。同じ種類は最新だけ残し、最大6件。
| 種類（key） | 条件 |
|---|---|
| clothesUp | 服の上限を超えた |
| weight / weight100 | 60・70・80・90・100・110・120・130kgを初めて超えた |
| gain | 初期体重から +10・20・30・40・50kg |
| ratio15 / ratio2 | 初期体重の1.5倍・2倍 |
| bmi25〜bmi40 | 肥満1〜4度の境目（健康診断） |
| waist90 | 腹囲90cm（メタボ健診の基準） |
| reverse | りんご型：ウエスト＞バスト／洋梨型：ヒップがバストより20cm以上大きい |

セリフ：data.js の milestoneLines（共通。narr＝主人公の気づき、low／high）→ byFat（脂肪型ごとの上書き）→ heroines[].lines.milestone（ヒロイン固有）の順に上書き。{kg} {size} {prev} {gain} が数値に置き換わる。今入っている共通セリフは仮（全キャラ共通の口調）。

### 体重の上限
ヒロインごとに maxWeight を書けばその値（茜140kgの提案に対応できる）。書かなければ config.maxWeight（120kg）。

### 段階15の目安体重（段階15_目安体重_見直し）
stages の maxBmi は変更なし。目安は立ち絵とスリーサイズ表のためのもので、エンジンには影響しない。
採用済みの段階15の画像（沙耶・玲奈・小百合）は、目安より大きいがそのまま使う（2026-11-02 ユーザー決定・案A）。

## 見た目以外の変化を楽しむ（v0.9）
体重の変化はゆっくりにし（weightGainBoost 2.5→1.0。約7,000kcalの余剰で1kg）、表示は小数点1位まで。そのぶん、見た目以外の変化を多く見せる。

- **最近の様子**（部屋の画面。開閉できる）：今の体型段階に当てはまる「食生活・仕事・生活・性格・心理」など。中身は `life.js`（ヒロイン設定.md の〈太った後の性格・生活の変化〉から自動生成。元の資料を直したら作り直す）。好意未満のときは「親密度が低いまま太った場合」の出方を注記する。姫華の段階13〜15はルートで出し分け

- **服のサイズの移り変わり**：S → M → L … を記録して表示

## 攻略
- 親密度が **95**（特別の段階）に届いた時点で攻略（体重・体型は条件にしない）。その場で攻略イベント（capture）が流れる
- 攻略後: 好意の段階と同じく警戒しなくなる（差し入れ・訪問を断らない）、差し入れの回数制限なし、あいさつ等は「〇〇Captured」キーのセリフがあればそちらを使う
- 攻略後も体重の増え方は同じ。上限120kgまで育てられる

## マンション編（v0.7）

```
{
  id: 'hinata',            // 半角英字。画像ファイル名にも使う
  room: '102',             // 102〜104, 201〜204
  name: '南 ひなた', nameIsTemp: true,
  age: 21, job: '大学3年生',

  sizes: { bust: 82, under: 67, waist: 57, hip: 85 },  // 段階1のスリーサイズとアンダー
  maxWeight: 140,          // 任意。体重の上限
  bodyType: { frame: 'straight', fat: 'hidden' },
  mods: { habitDecay: 1, stretch: 1 },  // 任意
```

### セリフのキー
各キーは「親密度4段階ぶんの配列」`[[よそよそしい],[顔なじみ],[好意],[特別]]`。段階ごとに複数書けばランダムで出る。

| キー | 場面 |
|---|---|
| greetMorning | 朝の掃除中の挨拶 |
| packageReceive / packageLate | 荷物を渡したとき／遅れて渡したとき |
| rent | 月末の家賃回収（[0]嫌な顔 [1]雑談 [2][3]好意的） |
| giftDislikeWarm | 好意70以上で苦手な物を渡したとき |
| greet | 部屋を訪ねたとき |
| talk | 「話す」 |
| giftLike / giftNormal | 好物／普通の差し入れ |
| giftDislike | 苦手な物（段階なしの配列でよい） |
| full | 満腹で断る |
| wary | 警戒して差し入れを断る |
| refuseVisit | 警戒が高く訪問を断る（段階なし） |
| eatOut / homeCook | 外食／手料理 |
| stageUp | `{ 2:{low,high}, 3:{…}, … 15:{…} }`（段階2以降すべて）体型段階が上がった後の一言 |
| capture | 攻略イベント。文字列の配列を順番に表示 |
| greetCaptured など | キー名＋Captured。攻略後はこちらを優先（任意） |

セリフは短いやり取り（1〜2文）を基本にする。

## 画像（PixAI）の規約
- ファイル名: `img/<id>_<段階>.png`（例: `img/hinata_3.png`）
- 1ヒロインにつき段階1〜15の15枚（段階が増えたらその分追加）。同じ服装・ポーズ・構図で体型だけ変える
- 縦長 2:3（表示枠が2:3。例 832×1248）、全身〜膝上、背景はシンプル
- 未設定の段階は仮シルエットが表示される
