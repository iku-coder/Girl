v2.1（2026-11-02 データ検証セッション）：段階15の目安体重を「120kg」から「段階14＋BMI1.5分（BMI約44.25）」に変更したのに合わせて、段階15の倍率を見直した（`claude/段階15_目安体重_見直し.md`）。
v2.4（2026-11-03 キャラデザセッション、ユーザー指示）：洋梨型・りんご型の部位の配分を、段階によって変える方式にした（ルール10）。

## 見直した理由（v1の問題）
v1は「段階1の画像の約〇倍まで」を、体重比の平方根（現実の体の横幅の増え方）から決めていた。実際に作ってみると、次の問題が出た。
1. **ChatGPTは上限を守らず、だんだん大きくなる**：同じ服のグループの2枚目以降が、雪だるま式に太りすぎた（沙耶の段階10〜12、玲奈の段階11〜12、小百合の段階8）。段階1との比較は遠すぎて、ChatGPTが大きさをつかめない
2. **逆に、変化が小さすぎる段階もある**：沙耶・小百合の段階2→3はほとんど差が出なかった
3. **服が替わる段階で細く見えることがある**：沙耶の段階5は、ゆったりした服で体の線が隠れて段階4より痩せて見えた
4. **最終段階（段階15）は、何度作り直しても大きくなる**：沙耶・玲奈とも、段階14から大きく跳ねた。ユーザー判断で演出として採用
5. **採用された画像は、平方根の式よりかなり太い**：段階15で段階1の約2倍（玲奈の太ももは2.36倍）。アニメ調の立ち絵として、ユーザーはこの見た目を採用している
6. **りんご型のお腹は前に張り出すので、正面からの横幅は増えにくい**：雪乃は段階4→5でお腹がはっきり出たのに、横幅はほぼ同じだった

## v2のルール
1. **比べる基準を「1つ前の段階の画像」にする**：毎回、段階1（顔・アクセサリーの基準）と1つ前の段階（体型の基準）の2枚を添付する。服が替わる段階5・9・13も同じ
2. **上限と下限の両方を書く**：「2枚目と比べて約〇倍まで（〇倍以上）」。太りすぎも、変化なしも防ぐ。「2枚目より細くしない」も毎回入れる
3. **目安のカーブは採用済みの画像の実測から決める**：いちばん太る部位の横幅（段階1比）
   1.00 → 1.08 → 1.16 → 1.23 → 1.29 → 1.36 → 1.42 → 1.49 → 1.55 → 1.61 → 1.67 → 1.73 → 1.79 → 1.85 → 1.91
   1つ前の段階との比（＝毎回の上限）：段階2 1.09、段階3〜5 1.06前後、段階6〜14 1.05〜1.03、段階15 1.04（v2.1で変更。段階15の目安体重が段階14＋約4kgになり、ほかの段階と同じ増え方になったため。v2は2.00・上限1.08だった）
   下限は「上限の増え幅の4割」（例：上限1.05なら1.02倍以上）
4. **部位ごとに太り方を変える**：いちばん太る部位を1として、ほかの部位はその何割かだけ増やす（洋梨型・りんご型は v2.4 のルール10で段階ごとに配分を変える）
   - 洋梨型（玲奈・小百合・ことり）：腰・太もも 1.0／お腹 0.6〜0.7／胸の高さ（二の腕を含む）0.5（小百合は胸が大きい設定なので0.6）／肩の線（骨の幅）はほぼ変えない（v2.3で変更。v2.2までは肩・胸0.2〜0.45）
     - 変更の理由（データ検証セッション）：0.2では上半身がほとんど太らず、玲奈は段階8（+41kg）で太もも1.57倍なのに胸1.00倍になった。スリーサイズ表では胸の増え方は腰の約0.5〜0.6倍（玲奈：段階8でバスト1.32倍・ヒップ1.53倍、ことり：1.26倍・1.54倍）。現実でも洋梨型は「下半身に多くつく」型で、二の腕・背中・顔・お腹は体重とともに太る。正面から見た胸の高さの横幅には二の腕も入る
     - 洋梨型らしさは「いちばん横に広いのは腰・太ももの高さ」という順番で出す。指示文には「肩幅（骨の幅）は広げないが、二の腕・背中・胸・顔にも、腰・太ももの半分くらいの割合で肉をつける（上半身だけ細いまま残さない）」を入れる
     - 採用済みの玲奈・小百合の画像はそのまま。ことりは段階3以降を v2.3 の指示文に差し替え済み
   - りんご型（沙耶・雪乃）：お腹 1.0（雪乃は正面の横幅が増えにくいので0.7）／胸の高さ（二の腕を含む）0.35〜0.4／太もも 0.35〜0.4／肩の線（骨の幅）はほぼ変えない（v2.3で変更。v2.2までは肩・胸0.25で「手足は細いまま」と書いていた。スリーサイズ表でもバストはウエストの約0.3〜0.4倍、ヒップは約0.4倍の割合で増え、現実でもりんご型の二の腕・背中・顔・太ももは体重とともに太る）
   - ウェーブ骨格（雪乃）は「肩幅を広げない」を毎回入れる
5. **りんご型は数字より形で指示する**：「お腹を前に張り出させる」「ボールのような丸ではなく、脂肪でやわらかく下側がたるむ」「妊婦のような見た目にしない」
6. **服が替わる段階は「服がゆったりしていても体の線を隠さない」「2枚目より痩せて見えないように」を入れる**
7. **測り方**：背景を透過した画像で、肩・胸・お腹・腰・太ももの高さの横幅を測り、段階1比と1つ前の段階比を出す。フレアスカートは広がりで大きく出るので、目視とあわせて判断する
8. **段階15は「最終段階だから大きく」と書かない**（v2.1）：ChatGPTは120kg・最終段階を大きく描きがち。段階15の指示文では、体重を新しい目安（例：163cmなら118kg）で書き、「段階14の画像より約4kgだけ増えた程度。最終段階でも一段だけ大きくする」と入れる
9. **頭身と脚の長さを固定する**（v2.2、データ検証セッション）：雪乃の旧段階9の画像で、段階1（約7.2頭身）から約5.8頭身に変わり、頭が約1.25倍大きく、スカートの裾から下の脚が身長の30%→23%に短くなっていた。太ると顔は丸くなるが、頭の高さ・身長・股下は変わらない。毎回の指示文に次を入れる
   - 「頭の大きさ（頭頂からあごまでの高さ）、頭身、脚の長さ、股下・ひざ・腰の高さは最初の画像と同じにする。太っても頭全体を大きくしない。顔は横に丸くなるだけ」
   - 「頭頂から足の裏までの高さを、最初の画像と同じにする」
   - 確認：頭身（全身の高さ÷頭頂〜あご）が段階1の±5%以内か、ひざの高さが段階1とほぼ同じかを測る。二重あごはあごの下に足すもので、あごの位置は下げない
10. **洋梨型・りんご型は、段階で配分を変えて最後はほぼ均等に収める**（v2.4、2026-11-03 ユーザー指示）
   - 理由：配分を全段階で固定すると、上半身と下半身の太さの差が段階を追うほど広がり、いびつな体型になった（ことりの段階13〜15は太もも2.7〜2.9倍・胸1.6〜1.7倍）。ユーザー指示：「洋梨型は下半身から、りんご型は上半身から太りはじめ、最終的な体型はほとんど同じか、若干上半身か下半身が太い程度に収める」
   - 主の部位（洋梨型＝腰・太もも、りんご型＝お腹・胸の高さ）は、ルール3の標準カーブのまま
   - 従の部位（洋梨型＝胸の高さ・二の腕・お腹、りんご型＝腰・太もも）は、配分を段階で増やす：段階2〜4 0.35／5 0.40／6 0.45／7 0.50／8 0.55／9 0.60／10 0.65／11 0.70／12 0.75／13 0.80／14 0.85／15 0.88
   - 従の部位の段階1比の目安：1.03 → 1.06 → 1.08 → 1.12 → 1.16 → 1.21 → 1.27 → 1.33 → 1.40 → 1.47 → 1.55 → 1.63 → 1.72 → 1.80（段階2から）。段階15で主1.91：従1.80（差は約6%）
   - 1つ前の段階との比：段階8までは主のほうが大きく（太り方の特徴が出る）、段階9からは従のほうが大きい（もう一方が追いつく）。従の上限：段階2〜4 1.02〜1.03、5〜8 1.03〜1.05、9〜14 1.05前後、15 1.045
   - 指示文の体型の書き方は3つの時期で変える
     - 段階2〜6（太りはじめ）：「肉は主に（主の部位）につける。（従の部位）は少しだけふっくらさせる程度」
     - 段階7〜10（追いかける）：「（従の部位）も追いかけるように太りはじめる（主の6〜7割くらいの勢い）」
     - 段階11〜15（追いつく）：「（従の部位）が追いつくように同じくらいの勢いで太る。最終的には全身がほぼ均等に太り、（主の部位）が少しだけ太い程度にする」
   - 隠れ肥満型（全身均等）はこれまでどおり
   - 実際にやって分かったこと（2026-11-03、栞・怜・莉緒）
     - ChatGPTは太もも（下半身）を上限より太らせがちで、洋梨型では段階9で段階1比 太もも約2.0・上半身約1.4まで差が開いた。服がスカート→レギンスに変わる段階で特に脚を描き直される
     - 先行した部位は倍率の上限ではなく「（部位）は2枚目とまったく同じ太さのまま（もう十分に太いので、今回は太くしない）」と書くと止まる。「ほぼ同じ」「約1.02倍まで」では止まらない
     - 遅れた部位は「二の腕が太くなって袖がぱんぱん、脇腹と背中に肉がついて胴の横幅が広がる」のように具体的に書くと増える（栞の段階12で上半身1.15倍）
     - 結果：栞（洋梨型）は段階15で 胸の高さ約1.9・太もも約2.1、怜（りんご型）は 胸約1.74・お腹約1.81・脚約1.8、莉緒（隠れ肥満型）は 胸約1.9・お腹1.7〜1.9 で、3人とも最後はほぼ均等に収まった
   - 適用：栞（洋梨型、段階2から）、怜（りんご型、段階5から）。完成済みのキャラ（沙耶・玲奈・小百合・茜・ことり）は作り直さない。雪乃（りんご型、作り直し中）に使うかはユーザー判断
11. **小柄（155cm前後）でウェーブ骨格の洋梨型は、下半身（腰・お尻・太もも）の伸びを0.8倍にする**（v2.5、2026-11-03 ユーザー指示）
   - 理由：渚（155cm・約6.2頭身）の段階5〜8（1回目）は、段階8で太もも1本 段階1比1.35〜1.37と、ルール10の目安（1.49）以内だったのに、ミニ丈で太ももが丸見えになり、脚の短い小柄な比率のため「下半身が太りすぎ」に見えた。標準カーブ（段階15で1.91）は160cm台のキャラを想定した値で、小柄な体では同じ倍率でも見た目が大きくなる
   - 太ももだけ止めると、腰・お尻だけが広がって裾のところで段差ができ、コマのような形になる。またChatGPTは腰を大きくすると太ももも一緒に太らせがち。なので腰・お尻・太ももをひとまとまりで抑える
   - 主の部位（腰・お尻・太もも）の段階1比の目安（標準カーブの増分×0.8）：1.06 → 1.13 → 1.18 → 1.23 → 1.29 → 1.34 → 1.39 → 1.44 → 1.49 → 1.54 → 1.58 → 1.63 → 1.68 → 1.73（段階2から）。1つ前の段階との比は 段階5〜8で1.03〜1.05、段階9〜15で1.03前後
   - 従の部位（胸の高さ・二の腕・お腹）はルール10のまま。ただし段階9以降は主の部位の0.97倍までにして、上半身が下半身を追い越さないようにする：1.33 → 1.40 → 1.47 → 1.53 → 1.58 → 1.63 → 1.68（段階9から）。段階15で 主1.73：従1.68（差は約3%、洋梨型の形を残す）
   - 適用：渚（段階5の作り直しから）。同じ組み合わせの完成済みキャラ（ことり 150cm・栞 158cm）は作り直さない。今後の小柄なウェーブ×洋梨型にも使う。千早（162cm・ナチュラル×洋梨）は標準のまま
