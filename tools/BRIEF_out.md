# 出先での遭遇・会話イベントの執筆指示（共通）

ブラウザゲーム「ひだまり荘」の会話シーンを日本語で書く。全員成人。主人公は20歳・大学2年、ひだまり荘（ボロアパート）の管理人で、隣のマンション「ひだまりレジデンス」のオーナーでもある。ふくよかな女性が好みで、女性の身長・体重・スリーサイズが見える「観察眼」を持つ。ヒロインを差し入れや手料理で少しずつ太らせていく、のんびりした交流ゲーム。

## 種類（type）と場面
- **town**（街中）：主人公が大学・バイト・買い出しへ行く途中や帰り道に、街中（商店街・駅前・公園・コンビニ前・横断歩道など）でヒロインとばったり会う。ヒロインは仕事や用事で外出中。id「<id>_tw01〜」
- **shopping**（買い出し）：主人公がスーパー／コンビニで差し入れを買っているときに会う。カゴの中身、お菓子売り場、試食、特売、レジ（玲奈はスーパーのレジ係なので、その職場で会う形でもよい）など。id「<id>_sh01〜」
- **job**（バイト）：主人公のバイト先のファミレスに、ヒロインが客として来る。主人公は店員（注文を取る、おすすめを聞かれる、デザートを勧める、大盛り、ドリンクバー、閉店間際、ひとりで／同僚・家族・友だちと来る等）。id「<id>_jb01〜」
- **campus**（大学）：主人公と同じ大学のキャンパス（学食、講義室、図書館、中庭、購買、サークル棟など）で会う。大学生ヒロインだけ。id「<id>_cp01〜」
ゲーム側の前置きは無いので、**各シーンの最初の行は地の文で場所と状況を示す**（例：'（駅前の横断歩道で、信号待ちの〇〇…）' ではなく '（駅前の横断歩道。信号待ちをしていると、となりに栞が並んだ）'）。

## 1キャラ1種類あたり 17シーン
- tiers [0]（よそよそしい 0〜34）3個：`if: { tiers: [0] }`。会釈程度〜ぎこちない短い会話
- tiers [1]（顔なじみ 35〜69）3個：`if: { tiers: [1] }`
- tiers [2]（好意 70〜90）3個：`if: { tiers: [2] }`
- tiers [3]（特別 91〜94、まだ攻略前）3個：`if: { tiers: [3], captured: false }`
- 攻略後（95以上）5個：`if: { captured: true }`。恋人（栞は不倫関係＝人目を気にする）としての外での会話
- 体型の変化が話題になるもの（服がきつい、食べ歩き、試着、量が増えた等）を各段階に少し混ぜ、`minStage`（5以上など）で出し分ける。ただし各段階の3個のうち最低1個は条件なしで出るようにする（minStage を付けない）
- 食べ物が絡む場面を多めに（ゲームの主題）。選択肢で食べさせる流れには habit 0.01〜0.03

## 条件・効果・書式
- 選択肢は2〜3個。返事で反応と続きが変わる（aff -2〜+3、wary）。branch で違いも。新しいフラグを作るなら「<id>_o」で始める
- 主人公の名前は「〇〇」と書けばゲームが置き換える。**呼び方・一人称・口調は、そのキャラの既存シーンに必ず合わせる**（段階で呼び方が変わるキャラは、その段階の呼び方に）
- 既存の /home/claude/hidamari/scenes/<id>.js・/home/claude/hidamari/scenes/daily/<id>.js・/home/claude/hidamari/scenes/room/<id>.js（ひなた・沙耶は /home/claude/hidamari/scenes.js の中）の冒頭コメントと書き方を読んで、口調・関係性・設定をそろえ、内容が重複しないようにする
- キャラ設定は /home/claude/girl/docs/ヒロイン設定.md の「■…」の節（`grep -n "^■" /home/claude/girl/docs/ヒロイン設定.md`）。職業・生活・〈太った後の変化〉・攻略後の関係を生かす
- ファイル：**/home/claude/hidamari/scenes/out/<type>/<id>.js**。中身は `window.addScenes('<id>', [ …シーン ]);` だけ
- セリフ：ふつうの文字列＝ヒロイン、'（…）'で始まる文字列＝地の文、['p','…']＝主人公、['n','…']＝地の文。選択肢の text は主人公のセリフとして表示（'（…）'で始めると行動の描写）
- 条件キー：tiers, minAff, maxAff, flag, noFlag, weekend, slot, captured, minStage, maxStage, minMoney, chance, minHabit
- ノードのキー：say, aff, wary, building, money, habit, setFlag, clearFlag, branch, choices, prompt, next。選択肢のキー：text, line, if, aff, wary, building, money, habit, setFlag, clearFlag, say, next, silent
- 性的な描写はしない（攻略後も手をつなぐ・寄りそう程度）。体型を蔑む表現はしない
- 1シーンは短め（ノード2〜4個、セリフ合計4〜10行）
