# 室内イベント・自室に呼ぶイベントの執筆指示（共通）

ブラウザゲーム「ひだまり荘」の会話シーンを日本語で書く。全員成人。主人公は20歳・大学2年、ひだまり荘（ボロアパート）の管理人で、隣のマンション「ひだまりレジデンス」のオーナーでもある。ふくよかな女性が好みで、女性の身長・体重・スリーサイズが見える「観察眼」を持つ。ヒロインを差し入れや手料理で少しずつ太らせていく、のんびりした交流ゲーム。

## 書くもの（1人あたり 約24シーン）
1. **talk（部屋で「話す」）15個**：tiers [1]（顔なじみ）5個、[2]（好意）5個、[3]（特別・攻略済み含む）5個。各シーンの if に tiers を1つ。部屋でくつろぐヒロインとの会話。趣味、仕事・大学、食事、家族、過去、主人公への気持ち、体型や生活の変化（minStage/maxStage を一部で使う。太った話題は minStage 5 以上）。段階ごとに関係が深まるのが分かるように
2. **visit（部屋を訪ねたときにたまに起きる）3個**：部屋に入った瞬間の場面（料理中、着替えの途中で慌てる（描写は控えめに）、昼寝、食べている最中、模様替え、など）。tiers [1]〜[3] や minStage を使い分ける
3. **invite（自室に呼んだとき）3個**：if に `captured: true`。攻略後のヒロインが主人公の101号室に来た場面の、到着から少しの会話（101号室は祖父の荷物が残る6畳の和室。祖父の写真、ちゃぶ台など）。この会話のあと、ゲーム側で「手料理を振る舞う／一緒に夜を過ごす」の選択に進むので、そこで終わる自然な会話にする
4. **night（一緒に夜を過ごす）3個**：if に `captured: true`。二人きりの夜、灯りを消すまでの会話。互いに望んでいることがはっきり分かる、穏やかで甘い会話にする。最後は必ず `'（——部屋の灯りを消した）'` の地の文で暗転し、その後に `'（翌朝）'` と翌朝の短いやり取り（朝ごはん、照れ、その人らしい一言）で終える。**性的な行為・体の性的な描写は一切書かない**（暗転で省略する）。キスや抱きしめる程度の描写まで

- 主人公の名前は「〇〇」と書けばゲームが置き換える。設定どおりの呼び方の変化に合わせる
