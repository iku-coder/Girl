# 立ち絵プロンプト 体型タイプ別 v0.1

データ検証セッションで作成。PixAI用。9組み合わせ×15段階。仕様は `claude/体型タイプ仕様.md` を参照。

## 使い方
- `<キャラ外見>`（髪型・髪色・目の色など）と `<服装>` はヒロインごとに固定し、全段階で同じものを入れる。seed・構図も固定して体型タグだけ差し替える
- タグの効き方はモデルで変わる。段階間の差が小さすぎる／大きすぎる場合は `(obese:1.25)` などの数値で調整する
- 段階11以降は、現実と同じくタイプ差を弱めている（骨格タグの重みを下げ、お腹を共通で大きくする）
- 隠れ肥満型は段階2・3で見た目を1段階遅らせ、段階4で一気に追いつく（仕様書参照）
