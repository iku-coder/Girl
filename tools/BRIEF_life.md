# 生活習慣の会話イベントの執筆指示（scenes/life/<id>.js）

ゲーム「ひだまり荘」の会話を日本語で書く。全員成人。主人公（20歳・大学2年、ひだまり荘の管理人で、ひだまりレジデンスのオーナー）は、ふくよかな女性が好みで、女性の体のサイズが見える「観察眼」を持つ。ヒロインに食べさせて少しずつ太らせる交流ゲーム。体型は段階1〜15。

## テーマ：太っていくにつれて変わる「生活習慣」
3つの話題 × 3つの時期 × 各3本 ＝ **1人27本**。

### 時期（if の minStage / maxStage）
- 初期：`{ minStage: 1, maxStage: 5 }`
- 中期：`{ minStage: 6, maxStage: 10 }`
- 後期：`{ minStage: 11 }`

### 話題
1. **運動**
   - 初期：スポーツ・ジョギング・ヨガなど、ちゃんと運動している話（少し体が重くなった、続けているのに減らない等の気配）
   - 中期：散歩・室内運動（動画を見ながらのストレッチ等）・前より短い時間のスポーツ。息切れ、続かない
   - 後期：運動をやめた話。勤め先や駅までの歩き、階段の上り下りだけで「運動した」と言うようになる
2. **食生活**
   - 初期〜後期にかけて：食事の回数が増える（朝昼晩＋夜食、一日四食・五食へ）、間食が増える、好物が変わる（サラダ・鶏むね肉・スムージー → 揚げ物・鶏もも肉・ジュースなどの甘い物・カロリーの大きい物）
   - 初期はまだヘルシー志向が残り、中期は揺らぎ、後期はすっかり変わっている
3. **服装・見た目**
   - 人の目：初期はまだ平気〜少しずつ恥ずかしくなり、中期がいちばん人目を気にし、後期には人の目を気にしなくなる
   - メイク：派手・おしゃれ → ナチュラル → すっぴん
   - 服：派手・おしゃれ → 落ち着いた服 → ジャージや部屋着
   - 髪：派手・おしゃれな髪型や髪色 → 落ち着いた髪型・髪色 → ボサボサ、まとめていない、手入れしていない
   - 元から地味・制服・作業着のキャラ（巫女、警察官、主婦、パートなど）は、そのキャラの「ふだんの身だしなみ」を起点に、手入れが減っていく・楽な格好になっていく流れにする。ヒロイン設定の〈体型に合わせた服装・髪型の変化〉の節があれば必ずそれに合わせる

### 反応はいろいろに（1人の27本の中でまんべんなく）
変化したことが恥ずかしい／うまくいかない苛立ち・八つ当たり／「あんたのごはんのせい」と主人公を責める／言い訳・ごまかし／開き直り・吹っ切れ／（親しい間柄なら）甘え・照れ隠し。主人公の選択肢で反応が変わるようにする（なだめる・ほめる・からかう・食べ物を勧める 等）。

### 場面（type）を散らす
各「話題×時期」の3本は、別々の type にする。使える type：`morning`（朝の掃除中のあいさつ）／`evening`（夕方の掃除中）／`talk`（部屋で話す）／`visit`（部屋を訪ねたとき）／`town`（街中でばったり）／`shopping`（買い出し中に会う）／`job`（主人公のバイト先のファミレスに客として来る）／`campus`（大学。**大学生キャラだけ**：ひなた・雪乃・莉緒・澪・渚・姫華）。
- morning / evening / town / shopping / job / campus は、最初の行を地の文にして場面を示す
- talk / visit は部屋の中（visit は部屋に入った瞬間の場面）
- 親密度：talk・visit は部屋に入れる親密度35以上なので `tiers` は不要。morning・evening・town・shopping・job・campus は親密度0から出るので、親しい前提の内容なら `minAff: 35` や `tiers: [2, 3]` を足す。攻略後らしい内容は `captured: true`
