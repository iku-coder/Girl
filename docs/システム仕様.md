## オープニングとチュートリアル（v1.0）
1. **タイトル画面**：背景はひだまり荘の夕方。「はじめから」で主人公の名前を入力
2. **プロローグ**：真っ暗な画面に、主人公（一人称「僕」）の一人語りを10ページ。祖父の死、両親を知らずに祖父に育てられたこと、「若いうちは食べるのが先だ」、遺言でひだまり荘を継ぐ、4月1日に101号室へ引っ越す。スキップ可
3. **入居**：4月1日（水）の昼から開始。背景はひだまり荘の昼。祖父の家賃台帳とメモ「四月の家賃は、一日に集めに回ること」
4. **チュートリアル：最初の家賃回収**：ひだまり荘の住人全員（ドアに「家賃」）を回って4月分の家賃を受け取る。在室なら初対面の会話（scenes/_intro.js の intro シーン）→ 家賃を受け取る（行動を消費しない）。留守なら「家賃台帳のメモ：〇〇さん、夜なら部屋にいることが多い。夜に改めて来よう」。自室で「ひと休み」して時間を進め、帰ってきた人に回収。全員から受け取るとチュートリアル終了（遊び方の説明）。回収しないまま寝ると、残りは封筒で受け取って終了
5. 4月1日の平日の在室：昼＝小百合・ことり・雪乃、夕＝ひなた、夜＝ひなた・沙耶・玲奈・茜・雪乃

## 会話シーン（scenes.js）
朝の挨拶・荷物・家賃回収・部屋の「話す」は、すべて**選択肢つきの会話シーン**で進む。主人公の返答で相手の反応・親密度・その後の会話が変わる。

- **種類（type）**：morning（朝の挨拶）／package（荷物）／rent（家賃回収）／rentExtra（家賃回収の追加イベント。顔なじみのとき50%）／talk（部屋で話す）
- **選ばれ方**：条件（if）に合うシーンのうち、まだ見ていない（見た回数が少ない）ものからランダム。同じ会話が続きにくい
- **条件**：親密度の段階（tiers）、親密度の範囲、フラグ、荷物が遅れたか（late）、休日か、時間帯、攻略済みか、体型段階、所持金、確率
- **ノード**：セリフ → 効果 → 自動分岐（branch）／選択肢（choices）／次へ（next）。何段でも続けられる
- **効果**：親密度（aff）、警戒（wary）、建物の状態、お金、食習慣（habit）、フラグの付け外し
- **フラグ**：選んだ返答を覚えておき、後の会話や選択肢の出現に使う（例：「料理を作る」と約束 → 後日「覚えてる？」の会話。「なんだっけ？」と答えると親密度が下がる）
- **一度きり（once）**：身の上話など、1回だけのシーン
- 選択肢の表示中は他の操作ができない。親密度の段階が上がった通知や攻略イベントは、シーンが終わってから出る
- シーンが1つもないときは、data.js の lines（greetMorning など）を予備として使う
- 基本の親密度上昇（朝の挨拶 +3、荷物 +4/+1、家賃 +1/+3/+2、話す +4）に、選択肢の増減が加わる

書き方の詳細は scenes.js の冒頭のコメントを参照。

## 体型が変わる仕組み
- 体重変化（夜）＝（自炊分 ＋ 間食 ＋ 差し入れ・食事のカロリー − 維持カロリー）÷ 7000 × 増量倍率 × 体質
  - 増量倍率 weightGainBoost は **1.2**（v1.5・2026-11-04 ユーザー決定「今の1.2倍くらい太りやすく」）。増えるときだけ掛かり、減るときは等倍（ただし減るときはデブ体質の分だけ痩せにくい）
  - **増加の上限は設けない**（2026-11-04 ユーザー決定。一度入れた「1か月5.0kg」は撤廃）。1日に食べられる量＝満腹ゲージが実質の上限
  - **デブ体質**（2026-11-04 ユーザー決定。以前の「高い段階ほど太りにくい」方針を変更）：増えるときの倍率に、体質 ＝ 1 ＋ 0.06 ×（段階−1）を掛ける（段階8で×1.42、段階15で×1.84）。部屋の画面に「体質」を表示（×1.3未満 ちょっと太りやすい／×1.6未満 太りやすい／それ以上 すっかりデブ体質）。痩せるときは体質の倍率で割る（段階15なら痩せる量が約0.54倍＝痩せにくい）
  - 維持カロリー＝体重×28、自炊分＝維持カロリー×(0.97 ＋ 0.5×食習慣)
- **食べる量の区分**（2026-11-04 ユーザー決定で6区分）：点数＝食習慣(%)＋（胃袋の上限−40）÷1.4
  | 点数 | 0〜 | 25〜 | 50〜 | 80〜 | 115〜 | 160〜 |
  |---|---|---|---|---|---|---|
  | 区分 | 小食 | 人並み | よく食べる | 大食い | 底なし | 無尽蔵 |
  - 区分ごとのセリフ scenes/eat/<id>.js（`window.addEatLines(id, { talk, gift, full })`、各6区分）。talk＝部屋で「話す」とき35%でこちら（eatTalkChance）、gift＝差し入れを食べ始めた直後に70%で一言（eatGiftChance）、full＝満腹で断るとき（差し入れ・手料理とも、無ければ従来の lines.full）
  - 検査：`node tools/check_eat.js scenes/eat/*.js`
- **食習慣**: 食べさせるほど上がり（差し入れ+1%、外食+3%、手料理+4%）、毎日少しずつ下がる
- **満腹と胃袋**: 満腹ゲージが上限を超える差し入れは断られる。上限の8割以上まで食べると上限が+2広がる
- **警戒**（好意70未満のみ）: 差し入れの回数オーバー、満腹で断られる、体型が変わる、で上昇。60以上で差し入れ拒否、80以上で訪問拒否。毎晩 −10
- **ヒロイン別の補正**（任意）: `mods: { habitDecay: 0.5, stretch: 1.5 }`（食習慣の減り方・胃袋の広がり方の倍率。雪乃の提案に対応）

## 体型タイプ（体型タイプ仕様 v0.2）
- ヒロインごとに `bodyType: { frame, fat }`。ひなた straight/hidden、沙耶 straight/apple
- 現在エンジンで使っているのは「太ったときの反応」と、隠れ肥満型の仮シルエットの遅れ（段階2→1、3→2）だけ
- 画像は遅れを焼き込み済みの前提（hinata_2.png は段階1と同じ絵）。エンジン側では画像の段階をずらさない
- スリーサイズは v0.6 で実装。体型タイプをプレイヤーに見せるかは未決（今は開発メニューにだけ表示）

## 攻略
- 親密度が **95**（特別の段階）に届いた時点で攻略（体重・体型は条件にしない）。その場で攻略イベント（capture）が流れる
- 攻略後: 好意の段階と同じく警戒しなくなる（差し入れ・訪問を断らない）、差し入れの回数制限なし、あいさつ等は「〇〇Captured」キーのセリフがあればそちらを使う
- 攻略後も体重の増え方は同じ。上限120kgまで育てられる

## マンション編（v0.7）
- **条件**：ヒロインを**5人攻略**すると（config.mansion.unlockCaptured）、「祖父の荷物が気になった」と地の文が出る
- **祖父の通帳イベント**：101号室に「祖父の押し入れを調べる」が出る（時間は進まない）。見たことのない通帳（残高3億円）と、祖父のメモ「隣の空き地も、うちの土地だ。住む場所に困っている人のために、好きに使いなさい」が見つかる

- **マンションのヒロイン**：data.js の heroines に `building: 'mansion'`、`room: '101'〜'304'` で登録する。マンションが建つまで地図・イベント・体重計算のどれにも出てこない。建った瞬間に入居する
  - **貧乏設定なし**。家賃は月12万円（config.mansion.rentPerMonth。ヒロインごとに rent で上書き可）

```

  room: '102',             // 102〜104, 201〜204
  name: '南 ひなた', nameIsTemp: true,
  age: 21, job: '大学3年生',

  sizes: { bust: 82, under: 67, waist: 57, hip: 85 },  // 段階1のスリーサイズとアンダー
  maxWeight: 140,          // 任意。体重の上限

  mods: { habitDecay: 1, stretch: 1 },  // 任意

  schedule: { weekday: ['夕','夜'], weekend: ['昼','夕'] },
```

### セリフのキー
各キーは「親密度4段階ぶんの配列」`[[よそよそしい],[顔なじみ],[好意],[特別]]`。段階ごとに複数書けばランダムで出る。

| キー | 場面 |
|---|---|
| greetMorning | 朝の掃除中の挨拶 |
| packageReceive / packageLate | 荷物を渡したとき／遅れて渡したとき |
| rent | 月末の家賃回収（[0]嫌な顔 [1]雑談 [2][3]好意的） |
| giftDislikeWarm | 好意70以上で苦手な物を渡したとき |
| greet | 部屋を訪ねたとき |
| talk | 「話す」 |
| giftLike / giftNormal | 好物／普通の差し入れ |
| giftDislike | 苦手な物（段階なしの配列でよい） |
| full | 満腹で断る |
| wary | 警戒して差し入れを断る |
| refuseVisit | 警戒が高く訪問を断る（段階なし） |
| eatOut / homeCook | 外食／手料理 |
| stageUp | `{ 2:{low,high}, 3:{…}, … 15:{…} }`（段階2以降すべて）体型段階が上がった後の一言 |
| capture | 攻略イベント。文字列の配列を順番に表示 |
| greetCaptured など | キー名＋Captured。攻略後はこちらを優先（任意） |

セリフは短いやり取り（1〜2文）を基本にする。

## 画像（PixAI）の規約
- ファイル名: `img/<id>_<段階>.png`（例: `img/hinata_3.png`）
- 1ヒロインにつき段階1〜15の15枚（段階が増えたらその分追加）。同じ服装・ポーズ・構図で体型だけ変える
- 縦長 2:3（表示枠が2:3。例 832×1248）、全身〜膝上、背景はシンプル
- 未設定の段階は仮シルエットが表示される
