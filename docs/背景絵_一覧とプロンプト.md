時間帯の名前は morning / noon / evening / night。

### 実装時のメモ（基幹セッション向け）
- 足りない時間帯は近いものを使う：ヒロインの部屋・マンションの部屋は 朝→昼、夕→夜。外廊下は 朝→昼。外食は ファミレス=全時間帯で昼、定食屋=夕→夜、居酒屋=全時間帯で夜
- 外食の店はヒロインごとに好みで分けられる（例：data.js のセリフで「ファミレス」「居酒屋」と言うキャラはその店）
- マンションの外観の看板に「ひだまりレジデンス」の文字が入っている。マンション名を正式に変えたら差し替えが必要
- 細かい不一致（気にならなければそのまま）：101号室の窓の外が2階からの眺め、敷地・入口前の外階段の位置が外観と違う、マンションは正面に3列しか部屋が見えない
- ファミレスとマンションの部屋は、ほかより線が細く淡い絵柄。ユーザー判断でそのまま使う
- 立ち絵は中央に重ねる想定。スマホの縦長画面では中央を切り抜いて使う

## 外観の見た目（以降の背景はこれに合わせる）
- 外壁：こげ茶の縦板張り。屋根：赤さびの浮いた赤茶の波トタン
- 外廊下・柱・手すり・外階段：オレンジ色のさびが浮いた鉄
- 各部屋：茶色の玄関ドア（上部に小さな四角いすりガラス窓）、白い腰高窓と物干し竿、ドアの上の小さな外灯、電気メーターと蛇口、クリーム色の縦型洗濯機
- 敷地：ブロック塀と6口の集合ポスト、黄色と黒の縞カバーの電柱、ピンクの紫陽花の植木鉢
- 室内：6畳の和室、入口の横に流し台と1口コンロの台所、右に押し入れ（101号室は祖父の箱）

## 新しい背景を作るときのやり方
- 画風をそろえるため、**完成した背景を1枚添付して**「この画像と同じ画風で」と頼む（屋外は `apartment_noon`、室内は `room101_noon`、店は `eatout_teishoku_noon`）
- 時間帯の差分は「この画像と同じ場所・同じ構図のまま、時間帯だけ〇〇に変えて」＋時間帯のブロックで作る
- 共通の画風ブロック（末尾に付ける）：
```
ギャルゲー（ノベルゲーム）の背景美術。アニメ調で、線ははっきり、塗りは平らなベタ塗り寄り、影は1〜2段のくっきりした影。写実的な質感・厚塗り・細かすぎる描き込み・強いレンズ効果は避ける。人物・動物・文字・看板の読める文字は入れない。立ち絵を手前に重ねるので、画面中央はものを置かずすっきりさせる。横長3:2、1536×1024。
```
- 時間帯のブロック：
  - 朝：`時間帯は朝7時ごろ。斜めに差し込むやわらかい白っぽい朝日、空は淡い水色、影は長め。`
  - 昼：`時間帯は昼。明るい晴天、青空と白い雲、影は短くはっきり。`
  - 夕：`時間帯は夕方。オレンジ色の夕焼け空、建物の西側が赤く照らされ、影は長くオレンジがかった紫。`
  - 夜：`時間帯は夜。濃い紺色の空、裸電球や蛍光灯の暖かい黄色い明かりが窓や外灯からこぼれる。暗すぎず、物の形が分かる明るさ。`

## 追加の候補（v1.1）
今の行動（大学・バイト・買い出し・外食）と、ヒロイン設定に出てくる場所から選んだ。おすすめ順。
各プロンプトは「添付：〜」の画像を付け、末尾に時間帯のブロックと共通の画風ブロックをつなげる。

### D1 下町の商店街（昼・夕）`town_shotengai_<時間帯>.png`
用途：「買い出し」、商店街で働くヒロイン（小百合のお弁当屋、茜の雑貨屋など）と会う場面。添付：`apartment_noon`
```
添付した画像と同じ画風で、東京の下町の昔ながらのアーケードのない商店街の通りを、通りの真ん中から奥に向かって見た背景。両側に八百屋、肉屋（店先でコロッケを揚げている）、お弁当屋、和菓子屋、小さな雑貨屋が並び、色とりどりの日よけテント、店先の野菜のかごや品物、のぼり旗（文字は読めない）、自転車。頭上に電線と街灯の飾り。通りの中央は人が立てるように空ける。にぎやかで温かい雰囲気。
```

### D2 最寄り駅の駅前（朝・夕・夜）`town_station_<時間帯>.png`
用途：大学やバイトへの行き帰り、外出・待ち合わせのイベント。添付：`apartment_noon`
```
添付した画像と同じ画風で、東京の下町の小さな私鉄の駅の駅前を描いた背景。小さな駅舎と改札口、駅前の小さなロータリーにバス停とタクシー乗り場、駐輪場にぎっしり並んだ自転車、コンビニ、パン屋、ドラッグストア、立ち食いそば屋が並ぶ。高架ではなく地上の線路と踏切が奥に見える。駅名や看板の文字は読めない。手前の歩道の中央は人が立てるように空ける。
```

### D3 大学のキャンパス（昼・夕）`univ_campus_<時間帯>.png`
用途：「大学へ行く」、大学生のヒロイン（ひなた・雪乃など）と会う場面。添付：`apartment_noon`
```
添付した画像と同じ画風で、東京の私立大学のキャンパスの並木道を描いた背景。両側にケヤキの並木、奥に赤レンガ風の古い校舎と新しいガラス張りの校舎、ベンチ、掲示板（文字は読めない）、自転車置き場。並木道の中央は人が立てるように空ける。明るく開放的な雰囲気。
```

### D4 大学の学食（昼）`univ_cafeteria_noon.png`
用途：大学でヒロインと食事する場面（外食の代わりにも使える）。添付：`eatout_teishoku_noon`
```
添付した画像と同じ画風で、大学の学生食堂の店内を描いた背景。長いテーブルと椅子が並び、大きな窓から光が入る。奥にカウンターと食券機、トレーの返却口、壁にメニューのパネル（文字は読めない）。手前のテーブル席を正面から見た構図で、向かいの席は人が座れるように空ける。
```

### D5 コンビニ（昼・夜）`town_conveni_<時間帯>.png`
用途：主人公の「バイト」先、夜の買い出し・差し入れの購入。添付：`eatout_teishoku_noon`
```
添付した画像と同じ画風で、街のコンビニエンスストアの店内をレジの前から見た背景。レジカウンターとホットスナックのケース、おでんの鍋、奥に明るい棚が並ぶ通路と飲み物の冷蔵ケース、お菓子とパンの棚、入口の自動ドアの外に街の景色。店名やロゴは描かない。棚の商品のパッケージの文字は読めない。中央の通路は人が立てるように空ける。
```

### D6 銭湯の入口（夕・夜）`town_sento_<時間帯>.png`
用途：ひだまり荘は風呂なしで、住人は銭湯へ行く（沙耶など設定に何度も出る）。銭湯帰りのイベントに。添付：`apartment_noon`


### D7 近所の公園・河川敷（昼・夕）`town_park_<時間帯>.png`
用途：散歩やデート、ヒロインの運動・ダイエットのイベント。添付：`apartment_noon`
```
添付した画像と同じ画風で、東京の下町の川沿いの土手（河川敷）を描いた背景。手前は土手の上の遊歩道、草の生えた斜面の下に広い河川敷のグラウンドと川、向こう岸に低い家並みと鉄橋。ベンチと街灯が1つずつ。遊歩道の中央は人が立てるように空ける。のんびりした雰囲気。
```
