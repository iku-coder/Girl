# ひだまり荘（仮）体型タイプ仕様 v0.2

データ検証セッションで作成。ヒロインごとに「骨格タイプ」×「脂肪型」の組み合わせ（9通り）を持たせ、太り方・立ち絵・太ったときの反応を変える。立ち絵プロンプトは `claude/立ち絵プロンプト_体型タイプ別.md`。

v0.2の変更（キャラ設定セッション）：付与ルールを「ランダム」から「設定から決める」に変更。ひなた・沙耶・玲奈はランダムで決めたまま、雪乃以降に適用。

## 前提（検証メモ）
- 骨格診断（ストレート／ウェーブ／ナチュラル）は民間のファッション理論で、医学的な分類ではない。ゲームでは「体の枠と肉の質感」の目安として使う
- 洋梨型・りんご型は医学的にも使われる脂肪分布の分類。女性は洋梨型が多いが、体重が増えるとどの型でもお腹に脂肪がつきやすくなる
- 隠れ肥満はBMIが普通で体脂肪率が高い「状態」で、形の型ではない。ゲームでは「見た目の変化が遅れて、後から一気に出る型」として扱う
- BMI40前後（段階11〜）からは現実でもタイプ差が縮む。立ち絵も高段階では差を弱めている

## 付与ルール（v0.2）
- 骨格と脂肪型を、キャラの設定から1つずつ決める（ゲーム用の目安で、医学的な判定ではない）
- 一度決めたら変えない
- 根拠はヒロイン設定の〈体型タイプの根拠〉に書く
- 例外：ひなた（straight/hidden）、沙耶（straight/apple）、玲奈（natural/pear）は旧ルール（ランダム）で決めたものをそのまま使う

**骨格（生まれつきの体の枠）**…体格・運動歴・家系・外見イメージから決める
- ストレート：上半身に厚みがあり、肉にハリがある。グラマー、健康的、運動部経験、胸板が厚いイメージ
- ウェーブ：骨が細く華奢で、肉がやわらかい。小柄、色白、文化系、お嬢様、ずっと細かった
- ナチュラル：骨太で肩幅があり、手足が長い。長身、スポーツ経験、モデル体型、大柄

**脂肪型（どこから太るか）**…太る原因・食の好み・生活習慣から決める
- りんご型（お腹から）：お酒、揚げ物、ジャンクフード、夜食・まとめ食い、ストレス食い、座りっぱなしの生活
- 洋梨型（腰・太ももから）：甘いもの、ごはんやパンなどの炭水化物中心、少しずつの食べすぎ、立ち仕事、出産経験
- 隠れ肥満型（見た目に出るのが遅い）：もともと筋肉が少ない、運動しない、隠れ食い、小食から急に食べる量が増える、運動をやめて筋肉が脂肪に入れ替わる

**手順**
1. 骨格は「太る前の体」のイメージで決める
2. 脂肪型は「何を、どう食べて太るか」で決める（いちばん大きい太る原因を優先）
3. 既存キャラと組み合わせがかぶる場合は、設定に無理がなければ、近いもう一方の候補を選んでもよい

## 9組み合わせの太り方
| 組み合わせ | 太り方・見た目 |
|---|---|
| ストレート×りんご | 胸からお腹まで前に厚く張り出す。肉にハリがあり、樽のような重量感 |
| ストレート×洋梨 | 上半身の厚みに腰・太もものボリュームが加わり、全身グラマー |
| ストレート×隠れ肥満 | 見た目はハリがあって締まって見えるが、触るとやわらかい。段階4で一気に全身に出る |
| ウェーブ×りんご | 細い手足のまま、下腹からお腹だけが丸く出る |
| ウェーブ×洋梨 | 華奢な上半身と大きな腰・太ももの落差がいちばん大きい |
| ウェーブ×隠れ肥満 | 細く見えるのに全体がふにゃっとやわらかい。たるみやすい |
| ナチュラル×りんご | 骨太の大柄な体にお腹が乗る。がっしりした印象が残る |
| ナチュラル×洋梨 | 広い骨盤まわりと太ももが太くなるが、角ばった枠は残る |
| ナチュラル×隠れ肥満 | フレームに隠れていちばん気づかれにくい |

## スリーサイズの増え方（体重1kgあたり、cm）
現行（全員共通 B+0.7／W+1.1／H+0.85）を基準に、骨格で胸と腰、脂肪型でウエストと腰の配分を変えた。統計値ではなくゲーム用の目安。

| 組み合わせ | B | W | H |
|---|---|---|---|
| ストレート×りんご | +0.85 | +1.35 | +0.6 |
| ストレート×洋梨 | +0.85 | +0.9 | +1.0 |
| ストレート×隠れ肥満 | +0.85 | +1.1 | +0.75 |
| ウェーブ×りんご | +0.55 | +1.35 | +0.8 |
| ウェーブ×洋梨 | +0.55 | +0.9 | +1.2 |
| ウェーブ×隠れ肥満 | +0.55 | +1.1 | +0.95 |
| ナチュラル×りんご | +0.7 | +1.35 | +0.7 |
| ナチュラル×洋梨 | +0.7 | +0.9 | +1.1 |
| ナチュラル×隠れ肥満 | +0.7 | +1.1 | +0.85 |

- アンダーバストは全タイプ +0.45 のまま
- 段階11以降（BMI39〜）は全タイプのW係数に +0.2 を足す（お腹に集まる現実の傾向に合わせる）

## 隠れ肥満型の扱い
- 体重と段階の判定は他と同じ。立ち絵だけ、段階2では段階1の見た目、段階3では段階2の見た目を使い、段階4で追いつく
- 反応も同じ流れ：段階2・3は「数字は増えたのに見た目は変わらない」、段階4で「急に来た」

## 太ったときの反応
段階が上がった後の最初の訪問（stageUp）で、ヒロイン固有のセリフに加えて、体型タイプの反応を出す。

**表示の優先順**
1. ヒロイン固有の `stageUp[段階]`（今までどおり）
2. 固有セリフがない段階は、タイプ共通の反応（下記 typeReactions）
3. それもなければ地の文

固有セリフがある段階でも、脂肪型の反応を「気づいた場所」として1行目に足すと、タイプ差が毎回感じられる（基幹セッションで採否を判断）。

**段階の区切り**: 序盤＝段階2〜5、中盤＝段階6〜10、終盤＝段階11〜15。low／high の使い分けは stageUp と同じ。

## data.js 追加案（基幹セッション向け）
```js
// ヒロインに追加（ヒロイン設定で決めた組み合わせを入れる）
bodyType: { frame: 'wave', fat: 'apple' },   // frame: straight/wave/natural, fat: apple/pear/hidden
// 現在：hinata straight/hidden、saya straight/apple、rena natural/pear、yukino wave/apple、sayuri straight/pear、akane natural/hidden、kotori wave/pear

// config に追加
bodyTypes: {
  frame: {
    straight: { name: 'ストレート', bust: 0.15,  hip: -0.1 },
    wave:     { name: 'ウェーブ',   bust: -0.15, hip: 0.1 },
    natural:  { name: 'ナチュラル', bust: 0,     hip: 0 }
  },
  fat: {
    apple:  { name: 'りんご型',   waist: 0.25, hip: -0.15, visualLag: 0 },
    pear:   { name: '洋梨型',     waist: -0.2, hip: 0.25,  visualLag: 0 },
    hidden: { name: '隠れ肥満型', waist: 0,    hip: 0,     visualLag: { 2: 1, 3: 2 } } // 立ち絵の段階をずらす
  }
},

// 画像のファイル名は今までどおり img/<id>_<段階>.png（ヒロインごとに組み合わせが1つなので変えない）
// typeReactions: { fat: { apple: { early:{low,high}, mid:{…}, late:{…} }, … }, frame: { … } }
```
- 隠れ肥満の visualLag は画像の選択だけに使う（hidden の段階2で img/<id>_1.png を出す）。ただし生成時に段階2用として段階1相当を作るなら、ずらし処理は不要
