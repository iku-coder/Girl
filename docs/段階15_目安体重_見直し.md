# 段階15の目安体重の見直し（2026-11-02 データ検証セッション）

キャラ設定セッション・キャラデザセッション・基幹セッションへの申し送り。ユーザー了承済み。

## 何を変えたか
- **段階15（はちきれ）の目安体重**を「一律120kg」から「**BMI 44.25**（段階14の目安＋BMI1.5分）」に変える
- 段階15の**範囲（BMI43.5〜上限120kg、茜は140kg）とゲームの上限体重は変えない**。変わるのは、スリーサイズ表と立ち絵の指示文で使う「目安」だけ
- data.js の stages（maxBmi）は変更なし

## 理由
- 段階2〜14は「範囲の中央」なのに、段階15だけ「上限の120kg」だったため、段階14→15の増え方が身長でばらばらだった（163cmは+6kg、157cmは+15kg、150cmは+24kg）
- ほかの段階と同じ増え方（BMI1.5分、約4kg）にそろえる。ChatGPTが最終段階を大きく描きすぎる問題（倍率ルールの見直し理由4）の原因の一つでもあった
