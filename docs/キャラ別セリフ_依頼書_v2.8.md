# キャラ別セリフ 依頼書（v2.8 攻略後の楽しみ・SNS・職場の変化）

2026-11-09 基幹セッションから、キャラ設定セッションへの依頼。

## 背景
仕様案「攻略後と遊びやすさ」（`claude/攻略後と遊びやすさ_仕様案.md`）の仕組みを、試作版 v2.8 で入れた。今はどのヒロインも**共通の文**で動いているので、ヒロインごとの設定と専用のセリフがほしい。仕様の詳しい動きは `claude/システム仕様.md` の「v2.8」の節。

## 1. 全員分の設定（1人1行でよい）
| 項目 | 形 | 例 |
|---|---|---|
| 料理の腕 | 上手（good）・ふつう（normal）・苦手（bad） | ひなた：上手 |
| 得意料理 | 料理名1つ | ひなた：桜もちと肉じゃが |
| SNS | よく投稿（often）・ときどき（some）・しない（none）／公開・非公開／アカウント名／初めのフォロワー数 | 香蓮：often・公開・@karen_fit・8000 |
| あだ名 | 段階9と段階13で、職場・学校でつけられるあだ名 | 真央：「まんまる店長」→「ファミレスの女将」 |
| 職場の種類 | 自動で決まらない人だけ。食べ物の店（food）・体を使う仕事（body）・会社やお店の事務（office）・学生（student）・家にいる人（home） | |

今は仮の値で動いている（料理の腕は全員「ふつう」、SNS は香蓮・ことり・姫華・すみれ・花咲家・スレンダーズなどだけ公開、あだ名はなし）。

## 2. キャラ専用のセリフ（書けるキャラだけ。書かないキャラは共通の文）
- **cookForMe**（手料理を作りに来た一言）2つ、**cookTaste**（味見の一言）2つ、**cookPraise**（「全部おいしい」への返事）2つ、**cookTogether**（「今度は一緒に」への返事）1つ。苦手な人は **cookFail**（失敗して出前にする）1つ
- **cookTease**（「味見しすぎじゃない？」への返事）3つ：段階5〜8・9〜12・13〜15。**気持ちの流れの型どおり**
- **aikagi**（合鍵を渡す／交換するときの一言）1〜2つ
- **stayOver**（合鍵で101号室に来てくつろいでいる一言）親密度の段階4つ×1
- **stayBeg**（深夜に「お腹すいた」とねだる一言）2つ
- **liveTogether**（一緒に住むと決めた一言）1つ、**liveDaily**（同棲中の朝夕の一言）3つ
- **dateStart**・**dateEnd**（食べ歩きデートの始まりと終わり）各1つ
- **tripStart**・**tripEnd**（旅行の始まりと終わり）各1つ、**tripScale**（旅館の脱衣所の体重計を見たときの一言）4つ：段階1〜4・5〜8・9〜12・13〜15。型どおりに
- **snsPost**（SNSの投稿文）3つ。文中の `{food}` が食べたものに置き換わる。写真は〔写真：{food}〕のように書く
- **uniformUp**（制服のサイズが上がった一言）1つ（制服のある職場の人だけ）
- **nickname9**・**nickname13**（あだ名を本人が話す一言）各1つ
- **workLife6**・**workLife9**・**workLife13**（職場・学校での扱いの変化）各1つ。凛の体力測定・真理子の勤め先・姫華の学園祭など、専用の仕組みがある人はいらない

## 3. 特別な扱いの会話（あれば）
- 栞：デートは人目のない遠くだけ、旅行は夫に隠れて（偽名で泊まる、夫からの電話）。同棲はできない（合鍵まで）
- 桃瀬母娘・双子・同じ部屋の組（鷺沢家・西園寺家・夏目三姉妹・スレンダーズ・御堂家・花咲家）の、デート・旅行の一言

## 4. タワーの新しい住人の独自の仕組み（決めてほしいこと）
基幹セッションが書いた17人の基本の会話には、設定の〈ゲームバランスの提案〉の独自の仕組みはまだ入っていない。次の候補から、入れるものを決めてほしい。
- 鷺沢家：嫁姑の関係ゲージと料理対決、夫からの電話
- 西園寺家：しずくの毒見（綾乃への差し入れの1割がしずくへ）、共犯（しずく70以上で綾乃の食習慣が毎日上がる）
- 夏目三姉妹：1人が2段階先に進むとほかの2人が反応、三姉妹そろった夜の食卓、三姉妹ルート
- スレンダーズ：月1回のお笑いライブ（2人の段階の組み合わせでウケ方が変わる）
- 御堂家・花咲家：父の追放（静香の段階13）、両家の宴会、勉強会、夜の街（スナックで静香とルミに会う）
- 澄香：返済日の「査定」、段階13以降の工場の規格外品の差し入れ
- ひまり：料理で「多めに作る」と夜に取りに来る、園の行事の日
- あわせて確認：ジュリの一人称（仮に「ウチ」）、部屋割り（鷺沢家301・夏目家501・御影406・春野606・スレンダーズ706・御堂家801・花咲家802・西園寺家1301）、入居の順番（建て替えの3日後から7日ごと：ひまり→鷺沢家→澄香→夏目家→スレンダーズ→御堂家と花咲家→西園寺家）

## 書き方の決まり
- 主人公の名前は「〇〇」と書く（ゲームが置き換える）。地の文は（　）でくくる
- 1つのセリフは短く1〜2文。口調・一人称・呼び方は設定どおり
- 性的な描写はしない（夜は暗転して翌朝）
