# v2.1 キャラ別の会話（scenes/v21/<id>.js）

ゲーム「ひだまり荘」の会話を日本語で書く。全員成人。主人公（20歳・大学2年、ボロアパート「ひだまり荘」の管理人で、隣のマンション「ひだまりレジデンス」のオーナー）は、ふくよかな女性が好みで、女性の体のサイズが見える「観察眼」を持つ。ヒロインに食べさせて少しずつ太らせる交流ゲーム。体型は段階1〜15。親密度は 0〜34 よそよそしい／35〜69 顔なじみ／70〜90 好意／91〜 特別（95で攻略）。

仕組みはもう動いている。今は共通のセリフ（/home/claude/hidamari/data.js の commonLines の handGiftOk・handGiftNo・oburumai・careGift・careGiftShy・careGiftAccept、config.body）で動いているので、**キャラごとの口調・設定で専用版を書く**。仕様は project の「攻略ペース調整_仕様案」「身体の変化_仕様案」の内容を下にまとめた。

## 1ファイル＝1人。中身は3つの呼び出し
```js
window.addScenes('<id>', [ …doorGift シーン2本… ]);   // シーンの id は「<id>_d21_」で始める
window.addExtra('<id>', { lines: { …セリフ… } });
window.addBody('<id>', { phases: { … }, talk: { … } });
```

## 1. doorGift シーン 2本（type: 'doorGift'、if は書かない）
まだ親しくない（親密度0〜34）ヒロインの部屋のドアノブに、主人公が差し入れの袋を「管理人より」のメモ付きで掛けておいた。翌朝、玄関まわりの掃除中に本人と会い「ドアノブの袋、管理人さんですか？」と聞かれる場面。
- 選択肢は2つ：**正直に答える**（aff 1〜2。警戒の強いキャラは wary +2〜5 も）／**ごまかす**（「さあ、誰だろう」など。aff 0、本人の反応はキャラ次第。気づいている・いないなど）。どちらもヒロインの返事まで書く
- 2本は場面を変える（例：1本目は空の袋を返しに来る、2本目は「また掛けてありましたけど…」と困惑・期待・警戒など）。キャラの性格（警戒心、食いしん坊、遠慮がち、プライド）がはっきり出るように
- 呼び方はまだ他人行儀な段階（「管理人さん」など、そのキャラの初期の呼び方）
- ノードの書き方は既存の朝のシーン（scenes/daily/<id>.js の type: 'morning'）と同じ。say／choices／next／aff／wary

## 2. addExtra の lines（すべて文字列の配列。tier 別は「配列の配列」4つ＝よそよそしい・顔なじみ・好意・特別）
- `handGiftOk`：朝の挨拶・荷物・家賃回収のついでに差し入れを手渡されて受け取る一言。**tier 別4段**、各2つ
- `handGiftNo`：断る一言。**tier 別4段**、各1〜2つ
- `oburumai`：月1回の「大家のおふるまい」（玄関前の長机に、季節の料理〈花見弁当・焼きそば・流しそうめん・かき氷とたこ焼き・スイカ割りとバーベキュー・芋煮・焼き芋・おでん・年越しそば・お雑煮と餅・豚汁・ちらし寿司〉を並べて「ご自由にどうぞ」）に出てきた一言。献立名は出さず、どの月でも通じる一言を4つ
- `careGift`：ケア用品（保湿クリーム・デオドラント・擦れ防止のスパッツ・ミントタブレット）をもらった一言。**tier 別4段**、各1つ（低い段階は戸惑い・警戒、高い段階は照れ）
- `careGiftShy`：恥じらい期（段階9〜12、好意以上）にもらったとき。強く気にしているので、とても喜ぶ／恥ずかしがる。2つ
- `careGiftAccept`：受け入れ期（段階13〜、好意以上）。「塗ってくれる？」と頼む。2つ（背中にクリームを塗る程度。性的な描写はしない）

## 3. addBody（身体の変化）
```js
window.addBody('<id>', {
  phases: { 1: '強がり期（段階5〜8）の身体の変化への態度・対策', 2: '恥じらい期（9〜12）', 3: '受け入れ期（13〜15）' },
  talk: {   // 好意以上のとき、部屋で「話す」とたまに出る本人のセリフ。各項目、心理の3段階ぶん [強がり, 恥じらい, 受け入れ]
    smell:   ['…', '…', '…'],   // 体臭（汗・蒸れ）
    breath:  ['…', '…', '…'],   // 口臭・いびき
    hair:    ['…', '…', '…'],   // ムダ毛の処理
    stretch: ['…', '…', '…'],   // 肉割れ
    dark:    ['…', '…', '…'],   // 擦れ・黒ずみ
    toilet:  ['…', '…', '…']    // トイレ（回数・お腹を下す）
  }
});
```
- phases は「最近の様子」の「本人の様子」欄に出る1〜2文（地の文の説明。例：「几帳面なので、強がり期からデオドラントと制汗シートを常に持ち歩いている」）。性格が出るように（几帳面なキャラは対策が細かい、ずぼらなキャラは受け入れ期に処理をやめる など）
- talk は1項目1セリフ（文字列）か、地の文を挟むなら文字列の配列（'（…）' で始まる文字列が地の文）。強がり＝気づかないふり・言い訳、恥じらい＝強く気にする・近づかれるのを嫌がる、受け入れ＝冗談にする・気にしない
- 体の変化の共通の目安は data.js の config.body.items（text）。**描写は生活感のある短い1〜2文にとどめ、生々しくしない**。性的な描写はしない。トイレは冗談めかす・恥ずかしがる程度
- 体型タイプ（heroines.js の bodyType.fat：apple りんご型＝お腹・脇腹、pear 洋梨型＝太もも・お尻、hidden 隠れ肥満型＝二の腕・太もも、変化が遅い）に合わせて、肉割れ・黒ずみの場所を書く
