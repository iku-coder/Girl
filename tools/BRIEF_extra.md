ブラウザゲーム「ひだまり荘」の会話を日本語で書く。全員成人。主人公（20歳・大学2年、ボロアパート「ひだまり荘」の管理人で、隣のマンション「ひだまりレジデンス」のオーナー）は、ふくよかな女性が好みで、女性の身長・体重・スリーサイズが見える「観察眼」を持つ。ヒロインに差し入れや手料理をして、少しずつ太らせていく交流ゲーム。

## 1ファイル＝1人。中身は次の2つの呼び出しだけ
```js
window.addExtra('<id>', {
  birthday: 'MM-DD',            // 誕生日。設定資料に無いので、キャラに合う日を決める（双子は同じ日）
  lines: {
    party:      ['…', '…', '…'],          // 食事会（鍋・バーベキュー）で食べ始めたときの一言。3つ以上
    partyAbout: ['…{other}…', '…'],       // 食事会で、同席した別の住人に向けた一言。{other}＝相手の下の名前（敬称は自分で付ける：{other}さん／{other}ちゃん等）。2つ以上
    gossip:     ['…{other}…', '…', '…'],  // 掃除中に2人に会ったとき、もう1人（{other}）の体型や食べっぷりの変化をうわさする一言。悪口ではなく、驚き・うらやましさ・心配・からかい等そのキャラらしく。3つ以上
    compete:    ['…{other}…', '…'],       // 食事会で{other}と食べ比べになったときの一言。2つ以上
    jealous:    ['…{other}…', '…', '…'],  // 攻略後、主人公が他の攻略済みの住人（{other}）とも仲がいいことへの、軽いやきもち。3つ以上
    dietRefuse: ['…', '…', '…'],          // ダイエット中に差し入れ・外食を断る一言。3つ以上
    birthday:   ['…', '…'],               // 誕生日のケーキを受け取った一言（シーンが無いときの予備）。2つ以上
    clothes:    ['…', '…']                // 服を買いに行ったときの一言（予備）。2つ以上
  }
});
window.addScenes('<id>', [ …シーン… ]);
```

## シーン（1人25本）。id は「<id>_x」で始める
1. **diet（ダイエット宣言）2本**：`type: 'diet'`。体型が段階4以上になったヒロインが「ダイエットする」と言い出す場面。主人公の選択肢で
   - 説得する（「今のままがいい」「無理しないで」など）：**親密度で成否を分ける**。`branch: [{ if: { minAff: 70 }, next: 'ok' }, { next: 'ng' }]` のように。成功したノードに `setFlag: 'diet_stop'`（＝ダイエットをやめる。ゲーム側がこのフラグを見て終わらせる）と habit 0.02 前後
   - 見守る／応援する：aff +1〜2。ダイエットは続く（期間中は差し入れを断られ、終わるとリバウンドする）
   2本の if：1本は `{ minStage: 4, maxStage: 9 }`、もう1本は `{ minStage: 10 }`（重くなってからの宣言）
2. **dietEnd（ダイエットが終わった）2本**：`type: 'dietEnd'`。最後までやりきった直後で、反動で食欲が爆発しかけている（リバウンドの始まり）。照れ・開き直り・言い訳など。if は付けなくてよい（1本は `captured: true` 用にしてもよい）
3. **scale（体重計）3本**：`type: 'scale'`。体重計に乗って「{kg}kg を超えた」ことに気づいた直後の場面。セリフや地の文に `{kg}` と書くとゲームが数字（55・65・75…）に置き換える。段階で反応を変える：`{ maxStage: 6 }`／`{ minStage: 7, maxStage: 11 }`／`{ minStage: 12 }`
4. **clothes（服を買いに行く）3本**：`type: 'clothes'`。服のサイズが上がったので、主人公と駅前の服屋へ行く。試着、サイズ表示、店員、似合う服を選ぶ等。`{ tiers: [1] }`（顔なじみ）／`{ tiers: [2] }`（好意）／`{ minAff: 91 }`（特別・攻略後）
5. **birthday（誕生日）2本**：`type: 'birthday'`。主人公がケーキを持って部屋を訪ねる。`{ maxAff: 90 }` と `{ minAff: 91 }`
6. **season（季節の行事）13本**：`type: 'season'`、if に `season: '<行事id>'`。主人公が誘って二人で出かける／過ごす。中で `branch` を使い、親密度（tiers）や攻略後（captured）で反応を変える。食べ物の場面を必ず入れる
   - hanami（お花見・4月上旬・昼夕）／gw（ゴールデンウィーク）／tsuyu（梅雨・相合傘など）／tanabata（七夕・短冊）／matsuri（夏祭り・屋台）／umi（海・水着の話は体型を蔑まない範囲で）／tsukimi（お月見・ひだまり荘の敷地で月見団子）／halloween／xmas（クリスマス・ケーキ）／oomisoka（大晦日・101号室で年越しそば）／shogatsu（初詣・おせち）／valentine（バレンタイン・ヒロインがチョコを用意してくる）／hinamatsuri（ひな祭り・101号室でちらし寿司やひなあられ）

## 書き方
- 口調・一人称・主人公の呼び方は、既存のシーン（/home/claude/hidamari/scenes/<id>.js、scenes/daily/<id>.js、scenes/room/<id>.js、ひなた・沙耶は /home/claude/hidamari/scenes.js）と heroines.js（ひなた・沙耶は data.js の heroines）に**必ず**合わせる。段階で呼び方・口調が変わるキャラは、条件の付いていないシーン・セリフでは呼びかけを省く（既存の scenes/eat/<id>.js と同じ方針）
- キャラ設定：/home/claude/girl/docs/ヒロイン設定.md の「■…」の節（`grep -n "^■" /home/claude/girl/docs/ヒロイン設定.md`）
- 主人公の名前は「〇〇」。セリフ：ふつうの文字列＝ヒロイン、'（…）'で始まる文字列＝地の文、['p','…']＝主人公、['n','…']＝地の文。選択肢の text は主人公のセリフ（'（…）'で始めると行動）
- 選択肢は2〜3個。aff -2〜+3、habit 0.01〜0.03。条件キー：tiers, minAff, maxAff, flag, noFlag, weekend, slot, captured, minStage, maxStage, minMoney, chance, minHabit, season

- 性的な描写はしない（攻略後も手をつなぐ・寄りそう・口づけ程度まで）。体型を蔑む表現はしない
- 1シーンは短め（ノード2〜5個、セリフ合計5〜12行）
