# 気持ちの流れの型（2026-11-07 ユーザー決定）

全ヒロインが「強がり → 恥じらい → 受け入れ」の同じ流れだったため、性格に合わせて4つの型に分ける。
立ち絵の表情・ヒロイン設定の心理・セリフ・節目イベントは、この型に合わせて書く。
段階2〜4は、どの型も「まだ変化に気づいていない、または気のせいだと思っている」段階のまま。

## 型とキャラごとの表情（2026-11-07 ユーザー決定）
同じ型のキャラが全員同じ表情になるのを避けるため、二段構えにする。
- **型が決めるもの：その段階の「感情」**（下の4つの型の表）
- **キャラが決めるもの：その感情を「どう顔に出すか」**。各キャラの〈表情の変化〉の表（`claude/ヒロイン設定.md` の各キャラの節。表情の癖1〜2個と、段階1〜4／5〜8／9／10／11／12／13〜15の表情）
- 立ち絵の表情は、キャラの〈表情の変化〉の表に従う。下の「立ち絵の表情の目安」は、表がないときの予備
- 完成済みの立ち絵は、描き直すときにこの表を基準にする（今の絵をすぐ直す必要はない）

## 4つの型

| 型 | 段階5〜8 | 段階9〜12 | 段階13〜15 |
|---|---|---|---|
| 恥じらい型 | 強がり・言い訳（「明日から控える」） | 恥ずかしくて隠したい。人目を気にする | 受け入れて肩の力が抜ける。おおらかになる |
| 抵抗型 | 焦ってダイエットを宣言・決意 | 失敗して悔しい。涙目で食べてしまう。負けず嫌いで何度も挑む | 吹っ切れて、晴れやかに笑う。解放される |
| 満喫型 | 食べる幸せでにこにこ（太ったことにまだ無頓着） | 「また太っちゃった」と照れ笑い。恥ずかしさより幸せが勝つ | とろけるような幸せ顔で、主人公に甘える |
| 開き直り型 | 気にしない余裕の笑み | 一瞬あせるが、すぐ「文句ある？」と開き直る | 今の体に自信を持ち、堂々と色っぽい |

### 立ち絵の表情の目安（予備。キャラの〈表情の変化〉の表が優先。段階9〜12は段階ごとに変える）
- 恥じらい型：9 目をそらす照れ顔／10 困り眉で真っ赤／11 ぎこちない作り笑い／12 観念しかけた照れ笑い／13〜15 やわらかい笑顔
- 抵抗型：5〜8 決意のきりっとした顔・焦り顔／9 目をそらす照れ顔／10 悔しさで涙をためた顔／11 むっとした負けず嫌いの顔／12 力が抜けた苦笑い／13〜15 吹っ切れた晴れやかな笑顔
- 満喫型：5〜8 食べ物を前にしたようなにこにこ顔／9 ほっぺたを押さえた照れ笑い／10 「えへへ」と舌を少し出した笑顔／11 頬を赤らめた幸せそうな笑顔／12 満腹でうっとりした顔／13〜15 とろけるような甘えた笑顔
- 開き直り型：5〜8 余裕の笑み／9 一瞬ぎくっとした顔／10 ふんと鼻を鳴らした強気な顔／11 挑発するようなにやり顔／12 胸を張った得意げな笑顔／13〜15 自信たっぷりの色っぽい笑顔
- どの型でも、表情を変える段階では「表情だけは2枚目の画像をまねしないで、新しく描く」を入れる
