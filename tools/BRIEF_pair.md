## 書くもの：1ファイル＝外のヒロイン1人、シーン3本
```js
window.addScenes('satsuki', [
  { id: 'satsuki_op01', type: 'outPair', cast: ['chihaya'], if: { noFlag: 'op_satsuki_1' }, nodes: { start: { setFlag: 'op_satsuki_1', say: [ … ], choices: [ … ] }, … } },
  { id: 'satsuki_op02', type: 'outPair', cast: ['chihaya'], if: { flag: 'op_satsuki_1', noFlag: 'op_satsuki_2' }, nodes: { start: { setFlag: 'op_satsuki_2', … } } },
  { id: 'satsuki_op03', type: 'outPair', cast: ['chihaya'], if: { flag: 'op_satsuki_2' }, nodes: { … } }
]);
```
- 1本目：2人がそろっているところに主人公が来る。2人の関係が分かる場面
- 2本目：2人と一緒に何かを食べる（ゲームが2人に +600kcal・親密度 +2 を入れる）。2人の関係が少し動く
- 3本目：**住人が段階5以上に太ってから**出る（くり返し出る）。外のヒロインが住人の体型の変化に触れる（設定の例：小町「沙耶ねえ、最近まるくなったね」と言ってにらまれる、まどか「春香さま、今日も3つですね」、美鈴が太ると玲奈に「店長、あたしと同じ道たどってんじゃん」と笑われる）。外のヒロイン自身の変化に住人が触れてもよい。どちらの段階でも通じる、からかい合いと食べる流れに
- 各シーン：2〜4ノード、選択肢2〜3個（aff -1〜+2。食べさせる流れは habit 0.01〜0.02）
- セリフ：ふつうの文字列＝外のヒロイン（シーンの持ち主）、`['@<住人の id>', '…']`＝住人、'（…）'＝地の文、['p','…']＝主人公。選択肢の text は主人公のセリフ（'（…）'で始めると行動）。`{other}` は住人の下の名前に置き換わる
- 主人公の名前は「〇〇」。呼び方は2人とも、それぞれの親密度が顔なじみ以上の頃の呼び方で（段階で変わる人は、呼びかけを省いてもよい）
