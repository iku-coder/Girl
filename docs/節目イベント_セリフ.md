# 節目イベントのセリフ v0.1

2026-11-02 キャラ設定セッションで作成。`claude/1kg単位の変化_仕様案.md`（データ検証セッション）の「3. イベント」「5. セリフの量の目安」に対応するセリフ集。基幹セッションで data.js の `lines.milestone` と、脂肪型ごとの共通セリフに組み込む。

## 使い方
- **low／high**：stageUp と同じ。好意70未満は low、好意70以上か攻略後は high
- **差し込み記号**：`{weight}` 体重（キリのいい数字）／`{gain}` 初期体重からの増加（kg）／`{size}` 新しい服のサイズ／`{prevSize}` 前の服のサイズ／`{degree}` 肥満度（1〜4）
- **優先順**（仕様案どおり）：段階アップ ＞ ヒロイン固有の大きな節目（100kg・2倍・最初の服のサイズアップ）＞ 服のサイズアップ ＞ そのほか。1回の訪問で1つだけ
- ヒロイン固有のセリフがあるイベントはそちらを使い、ないものは脂肪型の共通セリフを使う
- 共通セリフは口調が中立なので、ヒロインに合わせて語尾を変えられるなら変える（雪乃は丁寧語、玲奈・茜は男っぽく、など）。変えない場合もそのまま使える

## 体重を見せるかどうか（心理の流れに合わせる案）
仕様案「6. 気になる点」への提案。プロフィール欄の体重表示を、心理段階で変える。
| 体型段階 | 心理 | 体重の表示 | 例 |
|---|---|---|---|
| 1〜4 | 気づいていない | 好意35以上なら本人が普通に言う | 「49kgくらいかな」 |
| 5〜8 | 強がり | 本人は教えない／少なめに言う（実際より−3〜5kg） | 「…ひみつ」「50kg台だし」 |
| 9〜12 | 恥じらい | 好意70以上なら小声で正確に教える。それ以外は「？？kg」 | 「…きゅ、92kg。誰にも言わないで」 |
| 13〜15 | 受け入れ | 自分から言う | 「今日は104kgだったよ〜」 |
- 隠れ肥満型（ひなた・茜）は段階2〜4で「数字だけ増えている」ことを本人が不思議がる
- 雪乃は体重計を持っていないので、段階8まで「わかりません」。健康診断のイベントで初めて知る

  hidden: { ... }
},
// ヒロイン固有
lines: { milestone: { firstClothesUp:{low,high}, weight100:{low,high}, double:{low,high} } }
