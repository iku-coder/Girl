# 食べる量の区分ごとのセリフ（scenes/eat/<id>.js）

ゲーム「ひだまり荘」：主人公（20歳・大学2年、ボロアパート＋レジデンスの管理人／オーナー）が、成人女性の住人たちに差し入れや手料理をして、だんだんぽっちゃり〜太らせていくブラウザゲーム。

## 区分（ヒロインの「食べる量」。食習慣と胃袋の大きさで決まる）
0 小食 / 1 人並み / 2 よく食べる / 3 大食い / 4 底なし / 5 無尽蔵（いちばん上。どれだけでも食べられる）
区分は体重とは別。痩せていても大食いになりうるし、太っていても小食のことがある。体型の話より「食べ方・食欲・食べる量に対する本人の気持ち」を中心に。上の区分ほど、食べることへのためらいが薄れ、食欲が本人のキャラクターに溶けこんでいく変化を描く（照れ・開き直り・幸福感など、そのキャラらしく）。

## 書くもの（1ファイル1人）
```js
/* 〇〇（名前）食べる量の区分ごとのセリフ */
window.addEatLines('<id>', {
  // 部屋で「話す」ときの短いやりとり。区分ごとに2つ以上。1つ＝セリフの配列（2〜4行）
  talk: [
    /* 0 小食 */   [ ['セリフ', '（地の文）', 'セリフ'], ['…', '…'] ],
    /* 1 人並み */ [ ... ], /* 2 */ [ ... ], /* 3 */ [ ... ], /* 4 */ [ ... ], /* 5 無尽蔵 */ [ ... ]
  ],
  // 差し入れを受け取って食べ始めた直後の一言（好き嫌いの反応のあとに続く）。区分ごとに3つ以上。1つ＝文字列1行
  gift: [ /* 0 */ ['…', '…', '…'], ... 6区分 ],
  // 満腹で差し入れ（や手料理）を断るときの一言。区分ごとに2つ以上。1つ＝文字列1行
  full: [ /* 0 */ ['…', '…'], ... 6区分 ]
});
```
- 「（…）」で始まる行は地の文（ナレーション）。それ以外はヒロインのセリフ。主人公のセリフは書かない
- 主人公の名前は「〇〇」と書く（ゲームが置き換える）。ただし呼び方はキャラの既存セリフに合わせる（管理人さん／オーナーさん／おにーさん等。名前で呼ぶキャラは〇〇くん・〇〇さん等）。親密度は35〜100のどこでも出るので、親しすぎず固すぎない、そのキャラの「顔なじみ〜好意」くらいの距離感で
- gift は「受け取った品」を特定しない（何の差し入れでも合うように）
- full は「断る」セリフ。上の区分ほど「断るのが珍しい」「まだ入るのに胃袋が追いつかない」など区分らしさを
- 性的な表現は書かない。体型への蔑みも書かない（本人の自虐はキャラ次第で軽く可）
- 口調・一人称・呼び方・設定は heroines.js の各キャラの lines と、scenes/<id>.js・scenes/room/<id>.js の冒頭コメントを必ず読んで合わせる
- 全部日本語。1行は短め（40字前後まで）

## 確認
書いたら `node tools/check_eat.js scenes/eat/<id>.js` で「エラーなし」になるまで直す。
