# 段階15のギャル化差分 指示文（24人分、2026-11-09）

対象：段階15の立ち絵があり、まだギャルではないヒロイン。花咲家・御堂家・姫華のぽちゃギャルルート・蘭・真理子は作らない。菜々など立ち絵がまだないキャラは、段階15ができてから追加する。
型は `claude/立ち絵プロンプト_全キャラ.md` の「段階15のギャル化差分」。服の色はキャラの髪の色や今の服に寄せ、双子・母娘は服を分けた。

## 採用記録
- ひなた（2026-11-09 採用）：`img/hinata_15_gal.png`。明るい茶色の盛ったハーフアップの巻き髪、ピンクのラメのチューブトップ＋白いミニスカート＋白い厚底サンダル、濃いメイクとピンクの長いネイル、とろんとした目の笑み。段階15と同じ大きさ（約1.00〜1.02倍）
- 沙耶（2026-11-09 採用）：`img/saya_15_gal.png`。黒の盛った巻き髪（紫のメッシュ）、黒いレザー風のホルターのミニワンピース＋黒い厚底サンダル。胸の先の形が出ていたので、Claude側でぼかして消した。ふくらはぎが段階15より太い（約1.2〜1.45倍）
- 玲奈（2026-11-09 採用）：`img/reina_15_gal.png`。金の盛った巻き髪、ヒョウ柄のホルターのミニワンピース＋黒い厚底サンダル。耳の飾りと手首のカラフルなブレスレットは、段階15の絵にもあるのでそのまま
- 小百合（2026-11-09 採用）：`img/sayuri_15_gal.png`。チョコレートブラウンの盛った巻き髪、ワインレッドのラメのミニワンピース＋同じ色の厚底サンダル。段階15のふんわりしたエプロンのワンピースより体の線が出たぶん、腰まわりの幅が変わって見える
- ことり（2026-11-09 採用）：`img/kotori_15_gal.png`。赤〜ピンクの盛った巻き髪、濃いピンクのラメのへそ出しトップス＋黒いレザー風のミニスカート＋黒い厚底サンダル、口を開けた笑顔。胸の先の形が少し出ていたので、Claude側でぼかして消した
- 気づいたこと：ぴったりしたつやのある生地（レザー風・ラメ）は、胸の先の形が出やすい。指示文に書いてあっても出るので、受け取ったら拡大して確かめる
