## ファイル
`/home/claude/hidamari/scenes/special/<id>.js`。中身は `window.addScenes('<id>', [ …シーン ]);` と、必要なら `window.addExtra('<id>', { lines: { … } });`（lines は文字列の配列。ほかのファイルの addExtra とは自動でまとまる）。シーン id は「<id>_s」で始める。新しいフラグは「<id>_s」で始める（下に指定があるものは指定どおり）。

## 書き方
- 口調・一人称・主人公の呼び方は既存シーン（/home/claude/hidamari/scenes/<id>.js・scenes/daily/<id>.js・scenes/room/<id>.js・scenes/extra/<id>.js）と /home/claude/hidamari/heroines.js に必ず合わせる。キャラ設定は /home/claude/girl/docs/ヒロイン設定.md の「■…」の節

- 性的な描写はしない。体型を蔑む表現はしない。1シーンはノード2〜5個、セリフ5〜12行
