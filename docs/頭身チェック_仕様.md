# 頭身チェック 仕様 v1.1

2026-11-03 データ検証セッションで作成。キャラデザセッションで、段階1の頭身を測り、ChatGPTで太らせても頭身・脚の長さが変わらないようにするための手順。
倍率（横幅）のルールは `claude/立ち絵_倍率ルール.md`（v2.2のルール9がこの仕様の要約）。

## なぜ必要か
- 雪乃の旧段階9で、段階1（約7.2頭身）が約5.8頭身になり、頭が約1.25倍に大きく、スカートの裾から下の脚が身長の30%→23%に短くなった
- ChatGPTは太った体を描くとき、頭身を下げて「かわいく」見せる方向にずれやすい。乙女・かわいい系の服や表情に変わる段階（茜・ことりの段階9〜15など）で特に起きやすい
- 現実では、太っても頭頂〜あごの高さ、身長、股下、ひざの高さは変わらない。変わるのは顔の横幅（丸くなる）と、あごの下の肉（二重あご）だけ

## 1. 測る場所（目印）
段階1の画像で、次の6か所の縦の位置（y座標、px）を読む。
| 目印 | 読み方 | 注意 |
|---|---|---|
| 頭頂 | 髪のいちばん上 | **アホ毛・リボン・お団子・カチューシャの飾りは除く**。頭の丸みの上端 |
| あご | あごの先 | 二重あごがあっても、あごの先（口の下の骨の位置）で読む |
| 肩 | 肩の上の線（首の付け根の横） | 上着の肩パッドではなく体の線 |
| 股 | 脚の付け根（股） | スカートで見えない場合は「なし」。代わりにひざで判定する |
| ひざ | ひざの中心（ひざのお皿の高さ） | 左右で違うときは平均。サポーターの中心でもよい |
| 足の裏 | 靴底のいちばん下 | 足元の影は除く |

読み方：下の「2. スクリプト」で目盛り付きの画像を出し、Claudeが画像を見て読む（Readで画像を開く）。1〜2%の誤差は問題ない。

## 2. 計算式
- 身長 H ＝ 足の裏 − 頭頂
- 頭の高さ ＝ あご − 頭頂
- **頭身 ＝ H ÷ 頭の高さ**
- 股下の比 ＝（足の裏 − 股）÷ H
- ひざの高さの比 ＝（足の裏 − ひざ）÷ H
- 肩の位置の比 ＝（肩 − 頭頂）÷ H

### 許容範囲（生成した画像を段階1と比べる）
| 項目 | 合格 | 作り直し |
|---|---|---|
| 頭身 | 段階1の±5%以内 | ±8%を超える |
| 股下の比・ひざの高さの比 | 段階1との差が±0.02以内 | ±0.04を超える |
| 肩の位置の比 | ±0.02以内 | ±0.03を超える |
±5〜8%（または差0.02〜0.04）は目視で判断する。

## 3. スクリプト（キャラデザセッションで使う）
`measure_proportion.py` として保存して使う。Pillowだけで動く。
```python
# 使い方
#  1) 目盛り付きの画像を作る： python3 measure_proportion.py ruler 画像.png 出力.png
#     → 出力.png をReadで開き、目印のy座標（元画像のpx）を読む
#  2) 比率を計算する： python3 measure_proportion.py calc 頭頂 あご 肩 股 ひざ 足の裏
#     （股が見えないときは 0 を入れる）
#  3) 2枚を比べる： python3 measure_proportion.py cmp "段階1の6つの値" "比べる画像の6つの値"
import sys
from PIL import Image, ImageDraw

def ruler(src, dst, step=40, view_h=900):
    im = Image.open(src).convert('RGBA')
    bg = Image.new('RGBA', im.size, 'white'); bg.alpha_composite(im)
    im = bg.convert('RGB'); w, h = im.size
    sc = view_h / h
    v = im.resize((int(w * sc), view_h)); d = ImageDraw.Draw(v)
    for y in range(0, h, step):
        yy = int(y * sc)
        d.line([(0, yy), (v.width, yy)], fill=(255, 200, 200), width=1)
        d.text((2, yy - 6), str(y), fill='red')
    v.save(dst); print('saved', dst, 'original size', w, h)

def calc(top, chin, shoulder, crotch, knee, sole):
    H = sole - top
    r = {
        '頭身': H / (chin - top),
        '股下の比': (sole - crotch) / H if crotch else None,
        'ひざの高さの比': (sole - knee) / H,
        '肩の位置の比': (shoulder - top) / H,
    }
    return r

def show(name, r):
    print(name, ' '.join(f"{k}={v:.3f}" if v else f"{k}=なし" for k, v in r.items()))

if __name__ == '__main__':
    cmd = sys.argv[1]
    if cmd == 'ruler':
        ruler(sys.argv[2], sys.argv[3])
    elif cmd == 'calc':
        show('結果', calc(*map(float, sys.argv[2:8])))
    elif cmd == 'cmp':
        a = calc(*map(float, sys.argv[2].split())); b = calc(*map(float, sys.argv[3].split()))
        show('段階1', a); show('比較', b)
        d = (b['頭身'] / a['頭身'] - 1) * 100
        print(f"頭身の差 {d:+.1f}%  → {'合格' if abs(d) <= 5 else '目視で判断' if abs(d) <= 8 else '作り直し'}")
        for k in ['股下の比', 'ひざの高さの比', '肩の位置の比']:
            if a[k] and b[k]:
                diff = b[k] - a[k]
                lim = (0.02, 0.03) if k == '肩の位置の比' else (0.02, 0.04)
                print(f"{k}の差 {diff:+.3f} → {'合格' if abs(diff) <= lim[0] else '目視で判断' if abs(diff) <= lim[1] else '作り直し'}")
```

## 4. 手順
### 4-1. 段階1を作ったとき（キャラごとに1回）
1. 段階1の画像で `ruler` を実行し、目盛り付きの画像をReadで開く
2. 6か所の目印を読み、`calc` で頭身・股下の比・ひざの高さの比・肩の位置の比を出す
3. 結果を各キャラの `_キャラデザ.md` の「体の比率」の欄と、`claude/立ち絵_倍率ルール.md` の実測の記録に書く
4. 下の「5. プロンプトのひな形」に数値を入れて、①と各段階の指示文に組み込む

### 4-2. 段階2以降の画像ができたとき（毎回）
1. 背景透過・2:3への調整をしたあとの画像で、同じ6か所を読む（段階1と同じキャンバスの大きさにそろえてから測ると楽）
2. `cmp` で段階1と比べる
3. 「作り直し」が出たら「6. ずれたときに送る文」を送る。横幅の倍率（倍率ルール）を測るのは、頭身が合格してから（頭身がずれていると横幅の倍率も正しく出ない）

## 5. プロンプトのひな形
`{頭身}` などを段階1の実測値に置き換える。頭身は小数1桁、比は「約半分」「身長の約3分の1」など言葉にするとChatGPTに伝わりやすい。
| 股下の比 | 言葉 |
|---|---|
| 0.45〜0.47 | 身長の半分より少し短い |
| 0.48〜0.52 | 身長の約半分 |
| 0.53以上 | 身長の半分より長い |

**① 最初に送る文に足す1行**
```
・体の比率は、どの段階でもこの画像と同じにする。頭の大きさは約{頭身}頭身（頭頂からあごまでが身長の約{頭身の整数}分の1）、股下は{股下の言葉}、ひざの高さもこの画像と同じ。太っても頭全体を大きくせず、顔は横に丸くなるだけ。脚を短くしない。頭頂から足の裏までの高さも、この画像と同じにする
```

**段階2〜15の毎回の指示文に入れる1行**（背景の行の前）
```
・体の比率：1枚目（最初の画像）と同じ約{頭身}頭身、股下は{股下の言葉}、ひざの位置も1枚目と同じ。頭を大きくしない。脚を短くしない
```

**スカート・ワンピースで股が見えない段階**（股下の代わりにひざで書く）
```
・体の比率：1枚目（最初の画像）と同じ約{頭身}頭身。ひざの位置は1枚目と同じ高さ（床から身長の約{ひざの比を%で}）。スカートの下の脚を短くしない。頭を大きくしない
```

**かわいい系・乙女系に変わる段階（例：茜・ことりの段階9〜15）に足す1行**
```
・かわいい雰囲気は服・髪・表情で出し、頭身は変えない（デフォルメしない、ちびキャラ風にしない）
```

## 6. ずれたときに送る文
```
頭が大きく、脚が短くなっています。体型と服はこのままで、最初の画像と同じ約{頭身}頭身に戻し、股下を{股下の言葉}、ひざの位置を最初の画像と同じ高さにしてください。顔は横に丸くなるだけで、頭全体は大きくしないでください。
```
- 頭は合っているが脚だけ短い場合：「脚が短くなっています。上半身はこのままで、ひざと足の位置を最初の画像と同じ高さに戻してください」
- 頭が小さく脚が長すぎる場合（まれ）：「頭身が最初の画像と違います。約{頭身}頭身に戻してください」
