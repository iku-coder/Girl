# キャラ別セリフ 依頼書（v2.2 チートデイ・深夜の外食・変化への気づき）

2026-11-04 基幹セッションから、キャラ設定セッションへの依頼。

## 背景
試作版 v2.2 で次の仕組みを入れた。今はどのヒロインも**共通のセリフ**で動いているので、19人それぞれの口調・性格に合わせた専用のセリフを書いてほしい。

| 仕組み | いつ出るか |
|---|---|
| **チートデイ** | 親密度35以上のヒロインの部屋で「チートデイにする」を押したとき（1人につき月1回）。その日だけ満腹ゲージの上限が2倍になり、食生活への効果も2倍になる |
| **深夜の外食** | 親密度70以上（深夜に部屋を訪ねられる）のヒロインを、深夜に「外食に誘う」で二郎系ラーメンかファミレスに連れて行ったとき |
| **変化への気づき**（任意） | 親密度35未満で部屋に入れないヒロインの体型の段階や服のサイズが変わっていて、次に会ったとき。主人公の心の声（地の文） |

仕様の詳細はプロジェクトの `claude/システム仕様.md` の末尾（「深夜の訪問・チートデイ・深夜の外食・外食のコース」「部屋に入れない人の変化に気づく」）を参照。

## 書いてほしいもの（1人あたり）

### 1. cheatDay（チートデイを告げられたときの一言）
- 親密度の段階ごとに **1〜2個ずつ**、3段階ぶん：
  - 顔なじみ（35〜69）
  - 好意（70〜90）
  - 特別（91〜・攻略済み）
- 例（今の共通文）
  - 顔なじみ：「今日はチートデイ！ 好きなだけ食べていいんだよね？」
  - 好意：「やった、チートデイ！ 今日は遠慮しないからね」
  - 特別：「チートデイだね。…〇〇くんが用意してくれるもの、全部食べちゃう」
- 体型を気にするキャラは迷う、食いしん坊は大喜び、プライドの高いキャラは素直に喜べない、など性格が出るように
- 香蓮には元から「チートデイ」の設定（自分で決める差し入れ2倍の日）がある。主人公が決めるチートデイとの違いに触れてもよい

### 2. lateMeal_jiro（深夜の二郎系ラーメン）・lateMeal_famires（深夜のファミレス）
- それぞれ **2個ずつ**
- 深夜に行けるのは親密度70以上だけなので、好意〜特別の口調でよい
- 夜中に食べる罪悪感、背徳感、開き直り、主人公と二人きりの深夜の特別感など
- 例（今の共通文）
  - 二郎系：「こんな時間にラーメン…背徳の味だね」
  - ファミレス：「深夜のファミレスって、なんでこんなにおいしいんだろ」

### 3. 変化への気づき（任意・書けるキャラだけ）
- **主人公の心の声**を、地の文で書く。全体を（　）でくくる
- 次の3種類を、各1〜2個
  - lowNoticeStage：前に会ったときより、ふっくらした
  - lowNoticeBig：段階が2つ以上上がった
  - lowNoticeClothes：服のサイズが大きくなった
- まだ親しくない相手（親密度0〜34）を見たときの文なので、呼び方は「〇〇さん」など距離のある形にする。そのキャラらしい見え方を入れる（例：沙耶のスーツのボタン、玲奈の作業着、ひなたの頬）
- 書かないキャラは共通の文が使われる

## 書き方の決まり
- 主人公の名前は「〇〇」と書く（ゲームが置き換える）
- 地の文は（　）でくくる
- 1つのセリフは短く1〜2文
- 口調・一人称・主人公の呼び方は、ヒロイン設定.md と既存のセリフ（heroines.js・scenes/<id>.js）に合わせる。段階で呼び方が変わるキャラは、その段階の呼び方で
- 性的な描写はしない

## 納品の形
プロジェクトに `claude/キャラ別セリフ_v2.2.md` として、次の形で19人分を書いてほしい。基幹セッションがゲームに組み込む。

```
## hinata（南 ひなた）
- cheatDay
  - 顔なじみ：…／…
  - 好意：…／…
  - 特別：…／…
- lateMeal_jiro：…／…
- lateMeal_famires：…／…
- lowNoticeStage：（…）
- lowNoticeBig：（…）
- lowNoticeClothes：（…）
```

対象の19人：hinata・saya・reina・sayuri・akane・kotori・yukino（ひだまり荘）、rio・rei・shiori・aoi・mariko・sumire・mio・nagisa・chihaya・rin・karen・himeka（レジデンスなど）。外のヒロイン（ヒロイン設定 v3.7・v3.8 で追加した9人）は、ゲームに組み込んでから別に依頼する。
